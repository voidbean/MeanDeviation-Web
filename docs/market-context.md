# 指数量价背景（第一版）

入口：`services/market_context.py`。已接入个股 AI prompt、盯盘计划的 technical_context、AI 校准和既有盯盘触发通知。不改变原规则触发门槛；尚无独立分钟级大盘警报或仪表盘。

- 上证、深成、创业板分别计算，绝不相加冒充两市总成交额。
- 成交额从本地快照千元换算亿元；涨跌以最近且不超过 7 个自然日的历史收盘为参考。
- 同时间成交额比较至少需要 3 个有效历史样本，同分钟必须有快照。历史样本最多查最近 20 个日K；实际受快照 7 日保留期限制。
- 预计全天额 = 当前累计额 / 历史同时间累计额占各自全天额比例的中位数。
- 样本不足：开盘 30 分钟后按 240 分钟交易时长外推，排除午休，明确低置信度。未到 30 分钟不预测。
- 仅当天且交易时长延迟不超过 3 分钟的数据用于预估/告警；历史日期不当作实时数据。收盘快照不是交易所最终清算额。
- 同时间额比 >=1.2 / <=0.8 分别标记放量/缩量，属于未回测启发式，不是交易信号。
- 指数仍涨但自日内高点回撤 >=0.5% 时标记冲高回落风险，不认定诱多，也不保证未来回落或卖出收益。缺失大盘背景不能阻塞个股风险退出。

限制：无专门两市总成交额数据源、无预估置信区间、无上涨家数/市场宽度；当前行情采集仍以本机采集时间而非上游行情时间标记新鲜度。历史快照累计额完整性依赖现有采集链路。以上指标仅辅助，不能作为全市场资金流向或诱多概率。
