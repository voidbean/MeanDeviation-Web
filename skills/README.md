## 使用说明

每个技能文件均包含：
- **核心原则**：提炼自阿狼原文的核心观点
- **触发条件**：何时应用该技能
- **操作规则**：具体执行步骤
- **原文引用**：关键语录，带时间戳

## v2 主要新增内容（2026-04 / 2026-05）

1. **3-4 子形态体系完善**：绞肉机行情 / 机构自救行情 / B 反 / 弱 C 强 C

8. **ST 风险识别**：F10 + 会计事务所审计报告检查
9. **业绩股（F 类）**：新增独立分类 + 财报季操作规则
10. **黑名单扩展**：ST / 减持 / X 多多 / 软件 ETF / 战争板块 / 风电
