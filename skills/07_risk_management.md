# Skill 07：风险管理与止损原则

## 概述

阿狼的风险管理以**提前预判 + 仓位控制 + 严格止损**为核心：能赚钱的时候多挣钱，需要自我保护的时候少亏点。他反复强调风控不是某一条止损线，而是**整套操作体系**——在每个节点先把"出现 X 就卖 X"写出来，再按纪律执行。

本文件的主体是两块：持久的风控原则与止损规则，以及**事件性风险剧本库**（本 skill 的核心资产，逐个事件给出前置信号、时段、典型走势、操作、结束信号、历史案例）。2026-07 那波下跌新增了三个重量级剧本——公募滚雪球踩踏、全球性杀杠杆普跌、业绩月调仓换股期；2026-08 又补上 4-4 收尾的右侧诱多陷阱。

---

## 核心原则

1. **保命优先于赚钱**：弱势盘面保命是主旋律，能少亏不亏已经比大多数人强（2026-06-10）。
2. **上涨 vs 下跌的胜率不对称**：上涨趋势买错最多不涨，下跌阶段要全对才能赢，不划算（2026-06-08、06-11）。
3. **本金优先于回本幻想**：钱挣不完但能亏完，没本金就接不住后面的反弹（2026-08-02）。
4. **高位只看量价，低位才看逻辑**：高位不要再看基本面逻辑，只看纯技术图形量价关系（2026-08-02，血汗泪的经验教训）。
5. **针对未知，控制仓位才是重点**：盘中很多杀盘（如量化主卖）无法预判，唯一应对是仓位（2026-05-21）。任何仓位都要有止损位，包括长线资金（2026-06-26）。
6. **贪的代价在调整行情里被放大**：调整行情不是不能吃肉，而是贪的代价比主升行情更大（2026-08-17）。
7. **随意操作本身就是亏损来源**：亏损重点不是持仓跌多少，而是在持仓跌的同时随意调仓和加减（2026-07-28）。
8. **判断半径要短**：外围事件太多、随时可能转向，只做本周 + 判断下周，不做几个月级别判断（2026-08-13）；也不要照搬别人的超额，能公开亮出来的是成功率已经很高的操作，带赌性质的从来不说（2026-08-06）。

## 风险等级分类

| 等级 | 特征 | 应对 | 历史锚点 |
|------|------|------|----------|
| 一级：日内波动 | 指数 1–2% 波动，无放量，主线未破位 | 不操作，持仓等待 | 2026-01-12 |
| 二级：短期调整 | 放量转缩量 + 收黑 K 破 5 日线，主线出现分歧 | 减仓至 50–60%，止损位看 5 日线 | — |
| 三级：阶段性调整 | 跌破关键支撑、主线集体退潮、融资盘出逃 | 减仓至 30% 以下，只留长线底仓 | 2026-03 破 4000 后量化每日硬止损 |
| 四级：系统性风险 | 流动性危机（黄金 + 美债同跌）、外围黑天鹅、持续放量下跌、杠杆连环爆 | 清仓或极低仓位，等情绪反转 | 2026-03-23 流动性危机；2026-07 杀杠杆 |

## 止损规则

### 个股止损

| 情况 | 止损动作 |
|------|---------|
| 收盘破 5 日线 | 减仓或清仓 |
| 跌破前一根红 K 最低价 | 卖出（趋势股） |
| 放量跌破昨天红 K + 量能多一倍且昨天没涨 | 立即减 |
| 龙头风向标死亡 | 清仓板块内所有持仓 |
| 发布减持公告 | 立即清仓，不论盈亏 |
| 严重偏离 BOLL 上轨后回落 | 减半仓 |
| 年报亏损 + 会计事务所未出具报告 | 立即拉黑，预防 ST |
| 板块发散到不正宗票 | 减核心，弃补涨 |
| 触发预设目标市值 | 拉升中逐渐减半 |
| 方向有明确利空、且有公募被迫出场 | 不参与（有利空的方向一定不如没利空的持续，2026-08-05） |

### 大盘止损

| 情况 | 止损动作 |
|------|---------|
| 指数放量跌破 5 日线 | 减仓至 50% |
| 指数跌破关键支撑位 | 减仓至 30% |
| 量化止损时段（13:00–14:30） | 不在此时段止损，要么早上卖要么尾盘卖 |
| 量化主卖再现（13:30 缩转放） | 无法预判 → 控制仓位是唯一应对 |
| 两融余额大幅缩水 | 警惕，减仓 |
| 黄线下穿白线 + 大幅放量 | 停止加仓 + 高位逢高减仓 |
| 日 K 跌破 60 线 + 结构未磨好 | 不抄底，等结构 |
| 处在前低等关键时间点 | **不割肉**，至少等一个反抽再决定（2026-07-09） |
| 支撑位直接失效（如 3900 不弹就炸） | 做好止损（2026-08-18） |

## 事件性风险剧本

### 剧本 A：公募滚雪球踩踏（2026-07 新增，本轮最重要）

- **前置信号**：某方向基金抱团拥挤（如海外链）+ 破位 + 除海外映射外没有上涨动力；龙虎榜显示真心做多的资金还在主动买，但个股照样大跌
- **时段**：破位后持续数周，直到外力介入
- **典型走势**：公募你一手我一手互相卖出 → 多杀多 → 不可能靠自身停止；根因**不是基本面而是信心**
- **对应操作**：减少品类持仓，不因为某个方向有反弹就去调仓；避开公募占比高的方向；操作目标从赚钱降为"今天的操作没有导致我多亏出去"
- **结束信号**：只能靠外力——政策指导，或海外映射带动（如议息降息打断卖出节奏），信心靠外力恢复
- **历史案例**：2015 年后与 2021 年都出现过同型踩踏，2026-07 这波下杀不逊于当时（2026-07-31 复盘）；2026-07-29 海外链大光的滚雪球卖出

### 剧本 B：全球性杀杠杆 / 普跌（2026-07 新增）

- **前置信号**：全球市场同步普跌；国内融资盘 + 基金散户同时被动出场
- **时段**：约一个月量级（2026-07 全月）
- **典型走势**：杠杆散户 + 基金散户连环爆；高位杀杠杆时还有人做反弹，低位小票反而被抽干流动性更严重——小票因联动大票爆仓被直接抽走资金，属于不可预见的无妄之灾
- **对应操作**：做指数不做个股（沪深300、半导体 ETF 这类）；低位小票认命，不去博；流动性只能靠 GJD 给
- **结束信号**：政策外力顶起来（GJD 兜底、逆回购大增等）；两融收缩速度放缓。政策力度边界：一个月内两融从 3 万亿爆到 2.7 万亿算市场行为，爆到 2 万亿就会有人被问责（2026-07-28）
- **历史案例**：2026-07-24 高位杀杠杆；2026-07-27 小票被吸干流动性；2026-07-31 定性为全球性普跌杀杠杆叠加国内公募滚雪球多杀多

### 剧本 C：业绩月 / 调仓换股期（2026-07 新增）

- **前置信号**：进入业绩与指引披露窗口；机构按业绩和指引把仓位调到下半年方向
- **时段**：业绩月全程（2026-07 起）
- **典型走势**：基本面上是调仓换股（主要是公募这个体量）；资金面上是被迫杀杠杆；情绪面上是防御方向与主线方向反抽轮动 → 板块极其混乱，这段非常难
- **对应操作**：以 ETF / 指数为主做级别 T，不做个股；主线判断不因业绩月的混乱而更改（如 AIDC 算力观点不变，等过完业绩月）
- **结束信号**：业绩月结束、机构调仓完成并达成一致 → 市场底才可能出
- **历史案例**：2026-07-23 定调；2026-08-12 重申 AIDC 是下半年主线、等过完业绩月

### 剧本 D：议息与加息（2026-05 ~ 07 合并整理）

- **前置信号**：美联储议息会议临近（连老美自己股市都要避这个）；换帅后第一次会议附近
- **时段**：议息前约 1 周 ~ 决议当晚
- **典型走势**：议息前资金不做单边动作、成交萎缩；若降息，可打断公募滚雪球式卖出，形成海外大反弹
- **对应操作**：基准判断是不会加息（2026-07-29）；议息前一律不重仓；若真加息则多低都要清，不要指望加息还能低开高走（2026-06-17 表述为一键清仓）；唯一例外是老美加息而我们逆周期降息，则不用清仓（几率低但存在）
- **量级参考**：加息这个万一约等于关税战的三倍威力，而且只是起步（2026-06-17）
- **结束信号**：决议落地，无论结果
- **配套宏观判断**：沃什上台最重要的事不是加降息或缩表，而是**改基数基准**，从底层统计开始让通胀不再可怕，所以海外链要看海外是否企稳（2026-06-08）；尾部风险是万一加息则全世界爆炸（2026-06-10）
- **历史案例**：2026-05-19 议息避让；2026-07-29 当晚议息前给出清仓分支

### 剧本 E：4-4 收尾的右侧诱多陷阱（2026-08-18 新增）

- **前置信号**：4-4 反弹进入震荡台阶收尾（3950-3930 → 3966-3903 → 接近 4000 实际 3992 -（3900-3888））；大家开始形成回落就抄底的节奏
- **时段**：4-4 高点第二次探测前后
- **典型走势**：**套人最多的不是 4000 附近**（那里大家都会卖），而是最后一次回落到 3900 附近——那里会有人加满杠杆右侧抄底，这才是机构本次要吃的利润；随后最后一次碰高，出一个极具诱惑性的右侧突破诱多，4-4（至少科技这边）结束
- **对应操作**：不在 3900 附近加杠杆右侧抄底；备好资金只做正 T；等第二次确认高点过不去后清科技 ETF
- **结束信号**：极具诱惑性的右侧突破诱多出现；事后看大部分科技平均反弹到 0.618
- **最差分支**：3900 不弹直接炸 → 做好止损就行
- **历史案例**：2026-08-18 冲 3992 回落当日给出该剧本

### 剧本 F：TACO 交易（川普讲话节点）

- **前置信号**：金银油同步跳水 / 当晚有讲话日程
- **时段**：次日盘前 ~ 9:30
- **典型走势**：盘前急跌 → 盘中回升
- **对应操作**：盘前定向做反向；盘中不追突发利好
- **结束信号**：讲话或飞机起飞，预期落地
- **历史案例**：2026-04-07 → 2026-04-08 TACO 两周

### 剧本 G：财报季鬼故事（4.15 / 4.30）

- **前置信号**：4 月 15 日临近，业绩预告陆续披露
- **时段**：4 月 15 日 ~ 4 月 30 日
- **典型走势**：未发财报票 + 高位标集体下杀；业绩股埋伏机构，超预期 → 高开砸，不及预期 → 直接摁
- **对应操作**：尽量持有已发财报的票，未发财报的不加仓、逐步减；找低位已出业绩、确定不会暴雷的做，这是不确定性中的相对确定性
- **结束信号**：年报 + Q1 全部出齐（4 月底）
- **历史案例**：2026-04-03 / 04-19 / 04-21 的财报季操作与业绩组合判断（年报差 + Q1 转好＝健康；年报好 + Q1 更炸裂＝最强；年报亏 + Q1 还亏 + 无会计师报告＝ST 风险）

### 剧本 H：量化时段与量化主卖（13:00-14:30）

- **前置信号**：上午缩量震荡；板块核心松动且全市场无接力方向
- **时段**：13:00–14:30，量化新规后重点窄至 13:30–14:00
- **典型走势**：分时缩量转放量 → 持续主卖 → 半小时打到 60 日线附近（2026-05-21 半小时从 4140 打到 4067，73 个指数点）
- **对应操作**：不在该时段止损（要么早上卖要么尾盘卖）；不在杀盘中抄底；无法预判 → 控制仓位；被中继触发的全市场量化卖盘期间，唯一动作是管住手
- **结束信号**：14:30 后量能拐头；或第二天未跌
- **配套规律**：量化新规 2026-04-06 实施后量化被弱化，同板块走势不再高度同步，但主卖依然存在、只是更难预判；微盘 / 黄线出新低会触发量化止损盘，而止损盘出来后资金还要买回去（2026-06-17）
- **历史案例**：2026-03 每天 10 点后量化主卖；2026-05-21 重现；2026-07-06 中继触发全市场量化卖盘

### 剧本 I：节假日两融出场

- **前置信号**：节前最后 1-2 天，两融账户提前提现 / 还款日硬性出场
- **时段**：节前出金日
- **典型走势**：盘中或尾盘卖压；节前最后一天可能出现放大量普涨
- **对应操作**：节前不重仓；节前最后一天放量普涨不追高
- **结束信号**：节后第一个交易日量能恢复
- **历史案例**：2026-04-29 出金日前机构抢先手明牌诱多

### 剧本 J：日元加息

- **前置信号 / 时段**：日元加息预期发酵（如 2026-06-04 美股盘前大跌部分因此）~ 加息落地
- **典型影响**：有限——日元最多加到 1，对比美债利率和美股收益还是太低；真实意图是延缓斩杀线，不是要带崩全球
- **对应操作**：影响也就一点而已，不必过度恐慌，但纳入海外链观察
- **结束信号**：加息落地
- **历史案例**：2026-06-04

### 剧本 K：外围跳水 / 周末外部升级

- **前置信号**：外围隔夜大跌、突发小作文；或临近周五、周末有升级风险
- **时段**：次日盘前 ~ 上午；周五全天
- **典型走势**：因为 T+1，量化收到小作文会**先砸**，机构也没办法，这是底层逻辑 → 等美股开盘跟亚盘低开后修复；周五资金在重新估值前选择不做不参与
- **对应操作**：不在低开时恐慌割肉，等修复；周五不加仓；垃圾行情里的垃圾消息不参与（2026-08-18）
- **结束信号**：亚盘 / 美股修复完成；周末风险时点过去
- **历史案例**：2026-06-23 外围利空低开修复；2026-06-26 openAI 上市延迟的传导链（开支方延期上市 → 回本周期加长 → 投资人预期降低 → AI 开支降低）；2026-08-07 周五避险

## 黑天鹅应对原则

黑天鹅不可预测，不去预防，而是靠平时多挣钱来增加抗风险能力；关键不是现在挣多少，而是不玩的时候能带出去多少（2026-06-15）。

| 阶段 | 仓位与黑天鹅承受度 |
|------|--------------------|
| 主升阶段 | 满仓也不怕，有利润垫 |
| 调整阶段 | 仓位小，伤害有限 |
| 不确定阶段 | 30% 仓位，最多亏 10% |
| 机构自救行情期间（2026-04） | 固定留 20% 应对仓，用于黑天鹅低位抄底 |
| 3-5 末段（2026-05） | 20% 应对仓改为提现避让，出来的钱不立即回场 |

## 流动性危机识别

**信号**（需多个同时出现）：黄金大幅下跌、美债大幅下跌、A 股全面下跌、融资盘大规模出逃、量化止损盘持续压制。

**应对**：不抄底；只看谁在抄底、抄了多少钱；等技术底 + 情绪底共振——技术上已经不能判断底时，只有情绪反转才能出底（2026-03-23）。分层看：高位杀杠杆还有人做反弹，低位小票反而被杀流动性更严重，流动性只能靠 GJD 给（2026-07-24）。

## ST / 暴雷股识别

**看 F10 的方法**：① 看年报或一季报是否亏损；② 看会计事务所是否出具内部控制审计报告；③ 亏损 + 无报告（或否定 / 保留意见）→ 必拉黑；④ 周末停牌、即将 ST 的票属此类。

**背景（2026-03 ~ 04 历史案例）**：阿狼两个月中了 6 个暴雷票，创生涯纪录，自此第一次明确建议不做任何 ST / 星 ST / 准 ST 票。退市流程在完善，后续暴雷只会增多。另外明确点名有人做局收尾的票不要碰（2026-08-14 北部湾港）。

## 减持公告风险

- 个股出现减持公告＝立即出清，不论盈亏；哪怕方向对、票本身没问题，减持也不符合操作体系
- 大行情没有的时候，减持的公司、老板被查的、有大利空的一律不做——没有容错，大资金不愿做多这种票，跌不多但反弹时一定最弱
- 同方向 / 同板块 / 同细分内的减持票一律拉黑；历史案例：2026-04 泰嘉、天银机电

---

## 融资盘 / 两融风险监控

- 融资余额持续增加＝场外资金进场，行情可持续；大幅缩水＝杠杆资金出逃；爆仓＝强制平仓，可能引发踩踏
- 两融数据 T+1，要次日 9 点左右才能看到；能看到的两融只是最正规的一部分杠杆，大资金有拆借和过桥，小资金多是贷款（2026-04-29）
- 无法预知融资盘爆仓点与公募大规模赎回的第一波警戒线在哪里，所以只能用仓位应对（2026-03-23）

## 脆弱市场的踩踏风险

```
市场脆弱 → 经常发生恐慌盘 → 恐慌盘可能形成踩踏
  → 最大的踩踏 = 两融出清 + 机构出清
  → 2026-06-08 时这两者还没出现，大家已经受不了了
  → 2026-07 两者同时兑现：杠杆散户 + 基金散户连环爆 + 公募滚雪球多杀多
```

- 下跌行情没有主线，只有踩踏；上涨行情才有锚定的扩散跟涨。盘中有无数个小红 K，但只有一个是真反弹，抓错一个就是套牢（均 2026-07-28）
- 死亡螺旋机制：追高者被杀 → 变成带血筹码 → 被下一轮套利（2026-07-31）
- 做错一次的代价量化（2026-07-31 案例）：当日最高点追科创半导体 ETF，到收盘已不见 10%，再下打一次就是 15 个点——所以恐慌盘出现时大多数人也不敢抄底
- 亏钱效应会次日扩大化（2026-05-21 案例）：当日追高半导体的散户 -5% 起步，按当天科技振幅少的也有 -10%、多的可能 -15%

## 操作体系完整性 = 最大风控

整套操作体系 > 任何单一止损规则。2026-04-23 给出的完整清单：不追高 → 卖掉明牌说减的方向 → 持仓转到主线方向 → 明确说不新开仓的方向就不开 → 当天绝对不可能加大亏损 → 不随意抄底。

- 风险管理就是在每个节点先把"出现 X 就卖 X"的策略写出来（2026-04-29）
- 满仓状态下的风控＝不随意抄底 + 让整体亏损可控（2026-07-02）
- 减少个股持仓、转 ETF 和低位逻辑票、按指数结构挂上下、盘中减少一切随意性操作（2026-07-28）
- 承认能力边界：没能力预判某天某板块跌多少，也不承诺卖到最高点，也不因为单日超预期杀盘就改原计划；我说的不一定对，不要跟着我做（2026-08-07）
