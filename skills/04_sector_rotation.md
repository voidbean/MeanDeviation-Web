# Skill 04：板块轮动与题材选择逻辑

## 概述

阿狼的板块选择以**宏观主线 + 资金流向 + 龙头风向标**为核心，拒绝追热点、拒绝高切低到弱势板块。底层逻辑只有一条：**机构的钱只在同风偏的趋势里轮动，风偏不同的板块之间资金不会直接跳转。**

本 skill 的内容**时效性极强**。2026 年 7 月市场发生级别切换（大 3 上升浪 → 大 4 回调浪），上半年成立的主线表态在下半年大量失效，其中最典型的是海外链：上半年「大哥二哥光」是主线，**2026-07-23 之后才转为明确回避**。因此使用本文件时，**必须先看下方的「主线演化时间轴」确定这条主线走到了哪一段**，再去用后面的方法论。当前的主线排序与回避名单见状态层 `00_current_state.md`。

方法论部分（机构行情 vs 柚子行情、三段式收割、轮动判断规则、风向标体系、缩圈、套定律、风偏不跨类迁移、投资日历）是持久有效的，不随阶段变化。

## 核心框架一：机构行情 vs 柚子情绪行情

| 特征 | 机构行情 | 柚子（游资）情绪行情 |
|------|---------|---------------------|
| 走势 | 网格差价，每天涨一点 | 一段不回调的龙头抱团 |
| 持续性 | 较长，有切换 | 短，一波流 |
| 散户做法 | 不能追高，要换车 | 容易被逼空进场 |
| 收割方式 | 高切低 + 慢慢吸引散户接 | 把人逼到贪婪进场后崩 |

## 核心框架二：机构 → 柚子 → 散户的三段式收割剧本

```
阶段 1：机构抱团（"688 行情"）
  - 网格差价、每天涨一点；共识强、心齐
  - 跟着主线买就能赚
阶段 2：柚子接力（情绪行情 / 超短）
  - 板块内出现纯柚子接力票（中继、新医生这类）
  - 机构开始减仓，把筹码递给柚子
阶段 3：散户接盘（末段甩货）
  - 柚子完成最后一波后离场，散户被套在最高位
```

阶段 1 → 阶段 2 的切换信号：轮动节奏开始「心不齐」；板块内冒出纯接力票；短期资金从核心转向边缘。

核心圈材料的运作方式是同一套剧本的细分版（06-16）：不断出小作文 → 内部轮动上涨 → 先丢给量化 → 量化丢给柚子 → 柚子丢给散户。因此判断材料内部强弱时，看的是「哪边作文多哪边拉得多」，同时必须把出货因素算进去。

## 板块轮动判断规则

### 规则 1：高标退潮后，钱去哪里
- **错误思维**：高位板块的钱会去低位没涨的板块
- **正确逻辑**：钱只去**下一个加速的同风偏板块**；风偏不同（白酒、地产）的方向拿不到这些钱
- **反例（2026-05-21）**：半导体松动后资金没有外溢形成第二个承接方向 → 全市场被填坑 → 普跌

### 规则 2：高切低的时机
- **错误操作**：看见高位板块跳水就立刻切低位
- **正确时机**：高位板块加速结束 + 低位板块已经开始放量启动
- 早一步错过加速行情，晚一步跑不出来

### 规则 3：弱势板块内选股
- 弱势板块找**强的和核心的**，不找补涨的弱势票
- 高位板块的低位票＝跌得少，不是机会；低位板块的弱势票＝涨得少，不是补涨

### 规则 4：有梯队 vs 无梯队
- **有梯队**：龙头 → 次龙头 → 核心 → 补涨，可板块内轮动（商航、半导体、国算），适合调仓
- **无梯队**：一波流，整板涨整板跌（机器人、纯情绪票），只能一波操作

### 规则 5：风偏匹配 + 个股相性
- 找该方向与自己「相性对」的票，相性不对的直接拉黑
- 这不是玄学，是数据共振

### 规则 6：下跌行情里不要找主线（2026-07-28）
- 下跌行情没有主线，只有踩踏；锚定与扩散跟涨只存在于上涨行情
- 推论：在 4-3 筑底这类阶段问「现在锚定谁」这个问题本身不成立

### 规则 7：低位方向的持续性判定（2026-07-03 / 2026-08-06）
- 低位方向要走出**持续性**，前提是现在的主线全死，并且伴随整个市场大波动切换——这个条件基本不成立
- 但低位方向在无人关注时会**偷偷持续上涨**，因为板块成交量小，随便一点资金就能拉起来
- 因此低位方向的正确定位是**超额工具**（吃 3-5 个点），不是主线替代品；有消息刺激的优先，看不懂的宁可放弃

### 规则 8：量能决定能支撑几个高位板块（2026-08-05）
- 2WE-2.5WE 的量能只够支撑一个高位板块的主反；国产半导体与海外光在竞争同一批资金
- 推论：在大光有利空时，做国产半导体的资金会顺势踩一脚

### 规则 9：ETF 必须看成分股
- 买 ETF 埋伏某个方向前先核对成分股，否则买到的是别的板块（07-02 电网 ETF 排前三的是光纤）
- 08-07 大数据 ETF 因重仓科大讯飞被判为垃圾；08-14 国算没有对应 ETF，科创芯片 ETF 不能代餐

### 规则 10：外溢资金只做工具人，不去追（2026-06-26）
- 判断某板块行情的资金来源是不是「科技外溢」；若是，它的作用只是在关键位置不拖科技后腿
- 关注它在支撑 / 压力位的表现即可，不要从本来就挣钱的方向跑过去玩它

## 缩圈细分逻辑

震荡筑底 + 赛道拥挤阶段，主线选择从「板块轮动」收敛为「缩圈」——资金过于集中，只有核心确定性方向能不断获得资金介入。

```
赛道拥挤 → 缩圈 → 资金过于集中
  ↓
大科技杀小科技 / 核心科技杀边缘科技 / 确定性成长杀故事画饼
  ↓
蹭概念的先塌 → 非核心"没新消息进核心圈"的死也死不了、机会也不大
  ↓
资金不断介入「确定性」，市场会给出来谁是核心确定性（看信息收集能力）
```

配套认知：科技是总开关，「科技要是死了 别的生不了的」（06-05）；缩圈阶段非科技板块只是被搅动一下释放流动性的血包。

## 套定律（韬定律）＝华为芯片链＝国产卡扩产

- **本质**：已确认不可能合法买海外芯片，只剩国产卡一条路，所以国产扩产是唯一手段
- **选股口径**：买**和华为强关联**的国产放量环节——国产放量，所以该环节的材料和设备都涨
- **底层周期（06-29）**：扩产带来的材料消耗周期不会变，这就是「上半年设备、下半年材料」的核心底层逻辑；但高位看量价，低位才看逻辑
- **对待态度**：这是新名词且有官媒站台，哪怕不做也不要去看空
- **2026-07 延伸**：把国产 AIDC 当 RUBIN 机柜拆解，逐个细分选标，只留有交付且绝不会是海外链的标的

| 板块 | 风向标 | 观察要点 |
|------|--------|----------|

| 光 / 海外链 | 大哥（总龙头） | 大哥破中轨时没人敢反向拉光；光若结束，市场会跟随结束 |
| 商业航天 | 中国卫星（不做，只观察） | 第一标的上出家人榜＝退潮开始 |
| 玻璃基 | 京东方（消息源） | 卡在退潮期出现的板块承接不了外溢资金 |
| PCB | 胜宏（最先拉起表态） | 英伟达业绩指引中增量最大的方向 |
| 避险方向 | 银行、石油、贵金属 | 量能不放大却拉避险方向＝资金在流出，此时追早盘方向会被套 |

## 投资日历的重要性

板块 / 题材选择的第三层筛选：选**消息密集或准备消息密集**的方向。
- 必看：当月 + 下月的重大事件、会议、经济数据；都是公开信息
- 突发消息辨别：盘中不追、周末易反向、超预期落地最值钱
- 典型应用：08-03 判断券商带队的唯一条件是 8 月 LPR 双降；08-12 判断 AIDC 算力要「等过完业绩月」

## 冲突标记

- **低位方向的持续性**：2026-07-03 说「低位方向要走出持续性 那现在的主线都要死」，2026-08-06 又说低位方向在无人关注时「不断的偷偷各种涨了」，且 08-10 起把医药 / 电力 / 航天 / AI 软当成主要超额战场。两条都是方法论表述（一条讲主线级持续性，一条讲短期超额），差异待人工判定。
- **海外链的相对强弱 vs 是否参与**：2026-08-11 说「如果海外连没有利空 那确实就是一波打上去到半分位」，认为海外链信仰资金多、不怕外围；2026-08-14 又确认对海外链「没有任何变化」（在用国外利好出货、不参与）。前者是强弱判断，后者是参与与否，前后并存，差异待人工判定。
- **半导体设备 vs 通信 ETF 的年度判断**：2026 上半年多次以「26 年半导体设备 ETF 一倍于通信 ETF 涨幅」作为操作指导，2026-06-29 主动宣布该句「已经完成并结束」、不再作为操作指导。属自我作废而非外部矛盾，记录备查。
