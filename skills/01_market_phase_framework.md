# Skill 01：浪—段判定框架

## 概述

「浪—段」（大浪拆 X-1 ~ X-5、段内再拆小 ABC）**不是阿狼自创的体系**，是市场公认的波浪理论划分方式。阿狼自己也强调过技术结构要**以市场统一认知为准**，不是自己想怎么看就怎么看（2026-07-31）。

所以本 skill 要沉淀的**不是**"某年某月某日是第几浪"——那种写法只是一轮行情的编年史，换一轮就全废。要沉淀的是三样东西：

1. **层级怎么套**：大浪 → 段 → 段内小 ABC，以及不同标的之间的级别错位与共振
2. **每个段位靠什么可观测信号确认**——阿狼的实际贡献集中在这里：他给每个浪段配了量能、5 日线、兜底位、恐慌盘、缺口、半分位这类**能当天验证的条件**，而不是事后画图
3. **关键分叉怎么判**：回调 4 浪 vs 下跌一浪、反弹 vs 反转、X-4 反弹 vs 新一浪起点、失败 5 vs 继续杀

**本文件不回答「现在是第几浪」。** 阿狼当前的浪段判断（含当前有效点位）见状态层 `00_current_state.md` 第 1、2 节——那是**结论**，会过期；本文件是**得出结论的方法**，长期有效。

下文用 `X-1` ~ `X-5` 表示段位。本语料里的实例编号是上升浪的 `3-1`~`3-5` 与回调浪的 `4-2`~`4-5`，引用原文时保留原始编号以便回溯，但判据本身与这一轮究竟编号为 3 还是 4 无关。

## 一、判定总则

这几条是所有具体判据的前提，违反其中任何一条，后面的判定都不可靠。

| 总则 | 含义 | 来源日期 |
|------|------|----------|
| **走出来才算** | 可以按提前预判去操作，但只有真正走出来才能划分确切浪型，否则「都是乱说」 | 2026-08-06 |
| **以市场统一认知为准** | 技术结构不是个人解释权，要用大家共同承认的划法 | 2026-07-31 |
| **延伸浪不数时间** | 5 浪是延伸浪，延伸浪只看结构、不要数时间 | 2026-06-22 |
| **点位是推导产物** | 不要只看数字，要知道数字怎么来的；不知道推导过程就不该用 | 2026-06-04 |
| **短期节点时效极短** | 盘中算出的反抽点位只管到明天早上，再远的涨幅预判不出来 | 2026-05-26 |
| **级别可以错位但会共振** | 指数与高位板块常处在不同级别：指数走 X-4 时高位板块可能才走到 ABC 的 B 反；指数 X-5 对应高位板块的 C 杀 | 2026-08-05 |

**级别错位的一个重要推论**：指数的 X-5 可能是失败 5，但与之共振的高位板块 C 杀**肯定不是失败 C**，那是大级别调仓、逻辑重新来过的那种杀（2026-08-05）。所以不能用指数的乐观判定去推板块的安全性。

## 二、层级结构

```
大浪级别        上升 3 浪 / 回调 4 浪 / 5 浪
   └─ 段        X-1 ~ X-5（五段）
        └─ 小级别   段内小 ABC（A 冲高 → B 回踩 → C 拉升 或 A 杀 → B 反 → C 杀）
             └─ 再拆  日内/超短级别
```

判定顺序**必须自上而下**：先定大浪级别（决定还能不能接下一个大浪），再定段位（决定仓位刻度），最后定段内小 ABC（决定当下买卖动作）。跳过上层直接看小级别，是把反弹当反转的主要原因。

## 三、上升浪各段的识别判据

| 段位 | 形态特征 | 确认成立的信号 | 结束 / 转段信号 | 对应操作 |
|------|----------|----------------|-----------------|----------|
| **X-1 底部确认（磨底）** | 低位震荡、量能持续萎缩、无方向 | 日线级别出现 W 底 | W 底成型 | 轻仓观望，不主动加仓 |
| **X-2 突破确认（启动）** | 突破颈线、量能放大、红三兵 | 四步连续验证：日线 W 底 → 红三兵 → 突破颈线加速 → **关键点位站稳三天后量能暴涨** | 上述四步走完 | 逐步建仓买主线 |
| **X-3 主升浪（加速）** | 量能持续放大，主线加速，踏空资金涌入 | 增量资金进场顶起加速段 | **放量转缩量 + 收黑 K 跌破 5 日线** → 短期见顶（只是短期） | 满仓轮动；主升加速浪不言顶 |
| **X-4 调整（震荡）** | 量能萎缩，关键支撑附近震荡，主线退潮 | 见 3.1 三种子形态 | 放量突破区间上沿转 B 反 | 降仓、减少操作、做低位 T |
| **X-5 趋势延续 / 二次加速** | 调整结束后再次放量突破 | 见 3.2 加速完成的识别标志 | 见 3.2 | 重新加仓 |

**上升段通用铁律**：加速期不会换主线（2026-05-12）。

### 3.1 X-4 调整段内部的三种子形态

判断落在哪一种，决定的是"要不要参与"，而不是"买什么"。

| 子形态 | 识别特征 | 做法 |
|--------|----------|------|
| **绞肉机行情** | 窄区间反复震荡，没有趋势、没有主线、没有持续性（**上涨和下跌的持续性都没有**），纯存量博弈 | 激进区间 T（如 4 层加到 6 层、次日 T 回 4 层）；不会做 T 的直接降仓等关键时间窗口 |
| **机构自救行情** | 指数缓慢爬升或横盘但**没有普涨**；机构在板块间高切低，靠网格差价每天挣一点，吸引散户接盘 | 关键判别：**只有国家队才做得出普涨，机构只会结构性抱团**；按结构性行情对待 |
| **B 浪反弹** | 除非新高，否则看不到反转可能 | **有量就不是高点，缩量才容易出高点**；按一卖位 / 二卖位分批 T 出 |

**弱 C / 强 C（选股用）**：同一段行情里下跌的票大概率长度一样，所以 A 长则 C 短、A 短则 C 长，优先选 A 长 C 短的更安全（2026-04-19）。

### 3.2 X-5 加速段的微结构与见顶判据

- **小 ABC 走法**：A＝主升加速段 → B 反（正常到昨天二卖位附近）→ C 杀（量化主导，速度极快）。非标走法是 B 反当天直接打到 C 区域。
- **C 浪结束依据**：看结构，不看点位。
- **缺口规则**：下方**启动缺口不能补**，补了这里就是最高点；上方**衰竭缺口需要补**，补完机构就少一个技术麻烦点。
- **加速虹吸效应**：全市场量能在 3.5W 亿以下时，主升核心票每涨 1 个点约等于 50 只小票跌 1 个点，非核心资金被吸进核心。
- **衰竭浪＝多次诱多**：不是一次诱多，而是反复诱多，最后把散户挂在山顶。
- **防御板块的级别含义**：只拉单一防御板块（如白酒 / 光伏）＝**还不是**最后顶点，目的是把低位资金诱进去；白酒＋消费＋医药＋电力**全面**拉防御＝才是顶。
- **加速完成的识别标志**：缩圈到最后由大票带指数上、情绪小票反而不如大票的时候，加速就完成了（2026-06-30）。
- **危险信号**：当一个题材最赚钱的效应从超额个股**转移到板块指数（ETF / 基金）**上时，说明已经缩圈，容易出问题（2026-07-01 / 07-02）。

### 3.3 C 缓跌结尾与震荡筑底的判据

- **C 缓跌的结尾形态**：一定是在**不破大盘 60 日线、或破一下当天拉回**的前提下，某一天**一根阳线突破下跌通道**才算结束。在此之前的所有反弹都只是 C 缓跌中的反抽。
- **震荡筑底的找底逻辑（反直觉）**：找到指数底没什么用。关键不是跌到哪里，而是**谁会新进场、他们做哪个方向**。
- **没出恐慌盘＝没有新增量承接**：缩量且没有恐慌盘，意味着场外资金不会进来接。
- **总开关**：领涨主线（本轮为半导体）不止跌，整个市场都不会好，其他方向都只是超跌轮动、没有持续性。
- **措辞即表态**：把用词从「反抽」升级为「反弹」，本身就是对行情转好的定性（2026-06-15）。

## 四、回调浪各段的识别判据

| 段位 | 形态特征 | 确认 / 结束信号 | 说明 |
|------|----------|-----------------|------|
| **X-2** | 大级别 ABC 里的 **B 反段**；此时可能只有个别方向涨出双头，随后这些方向的独跌就是「还债」 | — | 2026-08-03 |
| **X-3 筑底** | 至少要把一个**完整 ABC 杀完** | 见 4.1 四个标志 | 上面真金白银守住位置，机构才会按「4 接 5」做 |
| **X-4 长级别反弹** | 至少一个月 K 线的反弹结构；**方向向上但幅度有限**，本质是切换过程 | 见 4.2 / 4.3 | 不是主升，别按主升预期做 |
| **X-5** | 大概率是**失败 5 浪** | 见 7.4 | 若走失败 5，后面就是主升 |

### 4.1 筑底段（X-3）完成的四个标志

1. 大盘走完一个**完整 ABC**（若下跌速度过快，要警惕级别升格为下跌 5 浪）
2. 上面**真金白银守住兜底位**——看到守住，机构才按「4 接 5」做；不守，资金就要退到更低的参照低点去拼搏
3. 兜底位**很难干净跌破**：大家都想等破位吃血筹，结果谁都不卖、上面还偶尔出小单兜底，只能继续磨到散户崩溃
4. **转 X-4 的确认条件**：资金测试兜底位成功 **＋ 指数级别连续 3 天站上 5 日线**（强调是"连续 3 天"，不是单日突破点位）

### 4.2 长级别反弹段（X-4）的性质与打法

**性质**

- **做 X-4 极难的三重原因**：基本面＝公募体量通过业绩和指引做调仓换股；资金面＝被迫的杀杠杆阶段；情绪面＝防御方向与主线方向反抽来回轮动（2026-07-23）
- **X-4 是一次性的**：大资金预期后面还会再跌一次，所以核心板块的 B 反和指数的 X-4 都**只有一次**；要信早信，在这波顶部才进场就是等死（2026-08-05）
- **必须靠核心主线带动**：主线不反弹，低位方向哪怕 4000 家上涨也扛不起指数（2026-08-03）；共振板块此时是**自救不是主升**，指数摆脱主线影响的可能性是 0（2026-08-13）

**安全打法**

- 放弃日内小波动，**只做「指数级别 3 天站上 5 日线」之后那段**，约 1 个月的指数级别安全期，但个股会大幅分化（2026-07-27）
- **操作越多错越多**；减少操作、按箱体做波动成功率更高
- 切换期板块方向混乱，**指数类工具（宽基、行业 ETF）比个股安全**

## 五、段内小 ABC 的通用识别

不写死具体点位——同一套结构在任何段位、任何标的上都复用：

| 小段 | 走法 | 成立条件 |
|------|------|----------|
| **A** | 第一波冲高，**测试上方压力位**后回落 | 冲高回落即 A 段结束 |
| **B** | 回踩到**下方支撑区** | 回踩不跳水即转 C |
| **C** | **放量过 A 段高点，且收盘站住不回落** | 两个条件同时满足才算 C 成立 |
| **C 后** | 再冲高后回落＝探测本段第一次高点后的**集体获利出场** | 进入第二次大震荡，等再探一次高点 |

**关键**：C 段的成立必须是"放量过前高"**加上**"收盘站住"两个条件，单靠盘中冲过不算。

## 六、一个段将要结束的通用信号

收尾链条与具体点位无关，只看节奏：

`震荡台阶一层层放大（后一层振幅约为前一层两倍）` → `大家形成「抄底节奏」，回落就有人接` → `最后一次碰高` → `出一个极具诱惑性的右侧突破诱多` → `本段（至少主线这边）结束`

- **不会一次就结束**：最强的 3 浪杀跌过去之后，长级别反弹浪正常（无外围利空）**一定会用第二次大震荡再探一次高点**，探不过资金才会彻底放弃
- **最大风险点不在高点**：真正套人最多的不是冲高那一次（那里大家都会卖），而是**最后一次回落到支撑区时的加杠杆右侧抄底**
- **事后特征**：回看时大部分主线个股平均反弹到 **0.618** 位置，弱的一部分、强的更少一部分，完全符合波浪理论

## 七、关键分叉判定

### 7.1 回调 4 浪 vs 下跌一浪（两者都是下跌结构，后续含义完全相反）

| 判据 | 回调 4 浪 | 下跌一浪 |
|------|-----------|----------|
| **月线级别支撑** | 企稳反弹（还能接大 5） | 破位后加速继续杀 |
| **套牢盘 / 利空文** | 套得够多**且没出利空文** → 修复重新走强概率更大 | — |
| **机构的卖法** | 预期能走出 4 → 卖只是减仓 | 预期走不出 4 → 清盘 |
| **ETF 波段投资法** | 大 3 继续用；到大 4 就停；大 4 接 5 继续用 | 大 4 转下跌一浪 → 清仓 |
| **下跌速度** | 正常速度走完 ABC | ABC 走得**太快** → 要警惕已升格为下跌 5 浪 |

### 7.2 反弹 vs 反转

- **唯一分界线**：**没有放量冲破半分位，一律按反弹处理**，不做反转预期——预期不高就不会被套在幻想上
- 反弹幅度分三档：**强**＝半分位上方一点 / **平均**＝跟指数差不多 / **弱**＝仅仅止跌横盘
- 选股目标：选到"平均值"那一档的票，通过超额操作吃到"强"那一档的涨幅

### 7.3 X-4 反弹 vs 新一浪起点

若 GJD 强行买出**连续多日阳线**（本轮的说法是 13 连阳），那性质就不是回调浪的 X-4 反弹，而是新一轮上升浪的 **5-1**（2026-08-06）。判据是**上涨的驱动来源**，不是涨幅。

### 7.4 失败 5 vs 下跌一浪延续

C 杀的深度在破位之前**算不出来**——上面还在守位置时任何预判都是假的。要看**破位那天上面是什么态度**：

- 破位时上面**继续守** → 直接按失败 5 处理
- 破位时上面**不守** → 按下跌一浪重新算位置

## 八、判定决策树

用相对变量（上方压力位 / 下方支撑区 / 兜底位），不填具体数字——具体数字见状态层。

```
第 0 步 — 确认大浪级别
  月线级别支撑企稳反弹          → 仍是回调 4 浪，还能接大 5
  月线级别支撑破位后加速继续杀  → 已转下跌一浪，ETF 类工具清仓
  套牢盘够多且没出利空文        → 4 浪概率大于下跌一浪
  ABC 走完但速度过快            → 警惕升格为下跌 5 浪

第 1 步 — 筑底段（X-3）还是反弹段（X-4）？
  指数没连续 3 天站上 5 日线            → 仍按 X-3 筑底处理，不做日内小波动
  连续 3 天站上 5 日线 + 兜底位测试成功 → X-4 成立，只做这一段
  上面强行买出连续多日阳线              → 不是 X-4，是新一浪的 5-1

第 2 步 — X-4 内部走到哪一小段
  第一波冲高测上方压力后回落     → A 段结束，等 B
  回踩下方支撑区且不跳水         → B 段，转 C
  放量过 A 段高点 + 收盘站住     → C 段成立
  C 后冲高回落 + 集体获利出场    → 进入第二次大震荡，等再探一次高点

第 3 步 — X-4 是不是要结束了
  震荡台阶逐层放大、抄底节奏已形成        → 接近尾声
  最后一次碰高 + 极具诱惑性的右侧突破诱多 → 本段（至少主线这边）结束
  第二次探高过不去                        → 清主线 ETF，本波反弹结束

第 4 步 — X-4 之后
  没有放量冲破半分位 → 一律按反弹对待，准备 X-5
  X-5 走失败 5 浪    → 后面就是主升
  破位时上面继续守   → 直接失败 5
  破位时上面不守     → 按下跌一浪重新算位置
```

## 九、点位的用法

点位是**判据的推导产物**，不是判据本身。阿狼反复强调不要只看数字，要知道数字怎么来的（2026-06-04）。以下是历史推导示例，**数字已随结构失效，保留的是推导路径**：

| 历史点位 | 怎么推出来的 | 推导方法可复用为 |
|----------|--------------|------------------|
| 4317-4375 | 上一年 12 月 W 底时算的，物理顶 4317，情绪顶可能高一点，所以给区间 | **W 底测算目标位，物理顶 + 情绪溢价 = 区间** |
| 4006 | X-2 结束确认的一环：站稳三天后量能暴涨 | **关键位站稳天数 + 量能验证 = 突破确认位** |
| 3900 一带 | 吃掉开盘恐慌盘后回到的中枢，绞肉机区间中值 | **恐慌盘消化后的回归中枢 = 震荡区间中值** |
| 4197 | 突发性利空导致后续进场资金买入情绪降低，所以有回踩风险 | **利空对增量资金情绪的折损 = 回踩风险位** |
| 3955 | 恐慌盘阈值：破了出大量恐慌盘触发量化卖盘，场外资金平铺进场吃割肉差价 → 普反；不破则净流入有限 → 只能抱团细分反弹 | **恐慌盘阈值 = 场外资金进场方式的分水岭** |
