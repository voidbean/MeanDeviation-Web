## 阿狼体系的总纲（2026-07-31 新帖 1 楼）

- 低位看逻辑，高位看量价
- 在保证个股基本面没问题的同时，严格以技术策略去操作执行，这是保命策略
- 操作跟着策略走，策略跟着市场走，不唯心

## 核心分析框架（按优先级排序）

### 第一步：判断浪—段位置（Skill 01）

浪—段是**公认的波浪理论划分**，不是阿狼自创；skill 里有价值的是他给每个段位配的**可当天验证的确认条件**。所以这一步要输出的是"依据哪几个信号判到这个段位"，不是背"某日是第几浪"。

判定顺序必须自上而下，**不要跳级**：
1. **大浪级别** → 上升浪 / 回调浪 / 下跌浪。关键分叉：**回调 4 浪 vs 下跌一浪**——月线支撑企稳＝回调 4；破位加速＝下跌一浪；ABC 走完但速度过快也可能已升格为下跌 5 浪
2. **段位 X-1 ~ X-5** → 上升浪：磨底 / 启动 / 主升 / 调整 / 二次加速；回调浪：X-2 B 反段 / X-3 筑底 / X-4 长级别反弹 / X-5 大概率失败 5
3. **段内小 ABC** → A 冲高测上方压力后回落 → B 回踩下方支撑不跳水 → C **放量过 A 段高点且收盘站住**（两个条件都要）

常用判据：
- 筑底段转反弹段：兜底位测试成功 **＋ 指数级别连续 3 天站上 5 日线**（是"连续 3 天"，不是单日破位）
- 长级别反弹段的安全打法：只做上述确认之后那段，不做日内小波动，操作越多错越多
- 反弹 vs 反转：**没有放量冲破半分位就都是反弹**
- C 缓跌结尾：不破 60 日线或破一下当天拉回，某天一根阳线突破下跌通道
- 筑底找底逻辑：不看"跌到哪"，看"谁新进场、做哪个方向"
- 级别错位：指数与板块可以不同步，指数走 X-4 时高位板块可能才走到 ABC 的 B 反
- 纪律：**只有真正走出来才能划分确切浪型**，预判可以指导操作但不能当结论

⚠️ 当前处在哪一浪哪一段，**不在 Skill 01 里**，去 `00_current_state.md` 第 1 节取。

### 第二步：量价确认（Skill 05）

- ⚠️ **先对齐行情阶段再取量能数字**——同一个量能在不同阶段含义完全不同，skill 05 的量能表是按阶段分层的
- 量能方向：放量 / 缩量 / 持续放量 / 放量转缩量 / 缩量涨 + 放量回落
- 黄线白线：黄线＝微盘与细分，白线＝核心；看盘重心随行情迁移
- 揉搓线 8 形态、BOLL 中轨定强弱、量化主卖识别（分时缩量突然转放量）
- 主力主动进场时往往是缩量，不是放量

### 第三步：仓位决策（Skill 02）

- 按阶段取基准仓位，不按情绪
- 三层结构：底仓 + 活动仓 + 黑天鹅应对仓；做 T 仓 ≠ 底仓
- 调仓不减仓 / 每日利润提取 / 高位方向做 T、低位方向不动
- 不上杠杆；不全空仓（空仓的人会在调整刚开始就忍不住买回）
- 70% 仓位 ≠ 70% 风险敞口（可能是十几只 2%~3% 的小仓位组合）
- 弱势期目标下移：从"赚钱"改为"今天的操作没有导致我多亏出去"

### 第四步：板块选择（Skill 04）

- 先查 skill 04 的「主线演化时间轴」，确认这条主线走到哪一段了
- 机构行情 vs 柚子情绪行情判别
- 缩圈细分：赛道拥挤 → 资金集中到核心确定性；蹭概念的先塌
- 风向标龙头是否健康；板块发散到不正宗票＝减核心、弃补涨
- 风偏不会跨类迁移（高位科技的钱去下一个加速方向，不会去白酒地产）
- 查黑名单（skill 11）

### 第五步：买卖信号（Skill 03）

- 是否出现明确信号；**不操作条件优先**（发呆原则、急杀不抄底、跳水幅度不够不买）
- 时间窗口：25 分内落地策略 / 避开量化时段 / 极限 15 分钟反应
- 假买点识别：缩量偷偷拉 → 放量套追高；教科书级二买是造出来的；**4-4 收尾的"极具诱惑性的右侧突破诱多"**

### 第六步：股票类型分类（Skill 11）

- 是否在黑名单？属于 A/B/C/D/E/F/G 哪一类？对应操作规则？
- 是否触发跨类型升级路径（打野→长线 / B2→A2 / A2→每日利润提取）？
- ETF 路径：注意**工具可得性**——有的方向根本没有对应 ETF，成分股要自己查（别拿名字近似的 ETF 代餐）

### 第七步：风险检查（Skill 07）

- 匹配事件性风险剧本 A~K（公募滚雪球踩踏 / 全球杀杠杆 / 业绩月调仓 / 议息加息 / 4-4 收尾诱多 / TACO / 财报季 / 量化时段 / 节假日两融 / 日元加息 / 外围跳水）
- F10 / 减持 / 审计风险
- 上涨 vs 下跌的胜率不对称：上涨买错最多不涨，下跌必须全对
- 针对未知，控制仓位才是重点

### 第八步：市场参与者验证（Skill 08）

- GJD：是否只兜不拉？**政策底 ≠ 市场底**（市场底要等机构调仓后达成一致）
- 机构：高标出货 + 向下挂单（调仓）还是真离场？是否在测兜单位置？
- 是否出现"机构 → 柚子 → 散户"收割链条？
- 公募滚雪球（"你一手我一手"多杀多）风险
- 散户：杠杆盘与基金散户连环爆；追高者会成为带血筹码

## 分析原则

1. **量能优先**：量能不支持就不操作
2. **阶段驱动**：仓位和操作由阶段决定，不由情绪决定
3. **风向标优先**：龙头死了就不做板块内其他票
4. **不追高**：只在确定性买点操作
5. **不马后炮**：基于当前信息判断
6. **策略是应对，不是猜**：写成"当出现 X 做 X、不出现 X 不做 X"
7. **相性原则**：相性不对的票直接拉黑
8. **先手优势**：开盘 25 分内落地策略
9. **超预期 ≠ 逻辑错**：烈度超预期不代表整体计划错，复盘后再决策
10. **公域边界**：学方法不抄操作

## 输出格式

1. **行情阶段判断**：大级别 + 小级别，依据是什么
2. **量能状态**：先说阶段，再说量能水平和趋势
3. **仓位建议**：基于阶段的仓位与三层结构
4. **板块方向**：值得关注的方向、在主线演化的哪一段、是否在黑名单
5. **操作信号**：是否有明确买卖信号；有无"不操作"理由
6. **风险提示**：匹配到的事件剧本 + 个股层面风险
7. **策略书写**："当出现 X 做 X"格式的动作清单
