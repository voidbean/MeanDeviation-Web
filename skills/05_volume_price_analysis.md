# Skill 05：量价分析方法

## 概述

阿狼将**量能**视为判断行情最核心的指标，优先级高于价格本身。核心逻辑：**有量才有价，量能是资金行为的直接体现，量能变化先于价格变化。**

2026-04 月起，阿狼新增了"**放量智障**"、"**白线主动下行化解智障**"、"**8000E 增量底线**"等更细颗粒度的盘口判读方法，量价工具箱明显丰富。

---

## 量能核心原则

### 原则 1：量能决定行情能否持续
- 放量 = 有资金进场，行情可持续
- 缩量 = 资金撤退，行情无法持续
- **原文**（2026-01-12）：
  > "有量就有价。"

### 原则 2：量能阈值判断
| 量能水平 | 含义 | 操作 |
|---------|------|------|
| 持续放量（> 前日）| 主升浪，资金持续涌入 | 持仓或加仓 |
| 温和放量 | 行情健康，可以操作 | 正常持仓 |
| 缩量（< 前日 30%）| 行情走弱，等待 | 减少操作，观察 |
| 缩量 7000 亿以下 | 高标出不来，不追 | 不操作 |
| 缩量 1 万亿以下 | 市场无法上涨 | 不操作 |

**原文**（2026-01-15）：
> "缩量 7000E，这么快的缩量高标出不来的，所以暂时不要去，等他们回暖那一下可以去抢抢反抽。"

**原文**（2026-01-16）：
> "缩量快 1WE，哪里能上去，用膝盖想都懂了。"

### 原则 3：放量转缩量是见顶信号
- 主升浪中：放量转缩量 + 黑 K 破 5 日线 = 短期见顶
- 调整中：缩量才能止跌，缩量是好事
- **原文**（2026-01-15）：
  > "最主要是量能，没有缩量，这才是问题，放量就必须快速拉上去，缩量才能磨底。"

### 原则 4：放量速度比放量本身更重要（2026-04-30 新增）
- 真突破：**快速放量**穿压力位 + 不缩回
- 假突破：慢慢放量 → 高位"放量智障"（量上去价不涨）
- **原文**（2026-04-30）：
  > "没有速度 放量智障 而且是快速放量 这里不卖 但是谨慎 随时防止放量减缓转缩量。"

### 原则 5：放量回退 1000E 才算高点（2026-04-08 新增）
- 当天 8000E 增量起来后，回退 1000E 以上才能确认日内高点
- 没回退 1000E 不要急着卖
- **原文**（2026-04-08）：
  > "我都和你说了 现在看什么 看量能 量能没有回退1000E以上今天就不是高点。"

### 原则 6：缩量调整 = 健康（2026-04-21 新增）
- 缩量调整 ≠ 行情结束
- 关键看是否在支撑位附近止跌
- **原文**（2026-04-21）：
  > "缩量调整啊。"

## 白线 / 黄线指标

阿狼频繁提到"白线"和"黄线"，这是他用来判断大盘资金流向的核心工具：
- **黄线在上**：大盘资金净流入（大资金主导），是加仓信号
- **白线在上**：小盘/个股资金活跃，大盘资金相对弱
- **黄白一起拉上去**：最强信号，可以满仓操作

**原文**（2026-02-04）：
> "其实今天白线全天在上，涨的大部分都是老登，你们买不对票肯定赢不了的，买对票，这个才是重点。"

**原文**（2026-02-05）：
> "低开，缩量，然后黄穿白，你们说符合什么。"（答：确认性买点）

### 黄白线进阶判断（2026-04-30 新增）
- **白线主动下来 = 化解放量智障**：散户没大量进场，资金切换没完成 → 行情还能继续
- **黄线下穿白线 + 大幅放量 = 顶部信号**：必须立即停止加仓 + 逢高减仓
- **黄白线交织缩大量** / **白线快速上穿黄线缩量**：谨慎，不要加仓

**原文**（2026-04-30）：
> "白线主动下来 化解了放量智障 证明进来的散户不够多 目前切换不完 行情还不能结束。"

**原文**（2026-04-29 楼友总结，阿狼背书）：
> "黄线迅速下穿白线且伴随大幅放量时，停止一切加仓并逢高抛售个股的动作。"

**原文**（2026-04-09）：
> "白线在上怎么派发 你会买吗 我肯定不买啊。"
> "今天白线在上 银保证还在杀 证明这里肯定不可能是反转位。"

## 量价形态识别

### 形态 1：缩量磨底（底部信号）
- **特征**：量能持续萎缩至冰点，价格在支撑位附近小幅震荡
- **含义**：卖盘枯竭，底部形成中
- **操作**：等待放量确认后介入

### 形态 2：放量突破（启动信号）
- **特征**：量能突然放大 + 价格有效突破关键压力位
- **含义**：大资金进场，行情启动
- **操作**：跟进，尾盘确认后买入
- **2026-04-08 标志日**：8000E 增量 + 跳空 3930 起来 = 这些资金的成本底线

### 形态 3：缩量反弹（虚假反弹）
- **特征**：价格反弹但量能未跟上
- **含义**：没有增量资金，反弹不可持续
- **操作**：减仓，不追高
- **原文**（2026-01-14）：
  > "缩量反弹，今天过不过新高我都会减仓。"

### 形态 4：放量不过新高（顶部信号）
- **特征**：量能放大但价格无法突破前高
- **含义**：上方压力大，主力出货
- **操作**：减仓
- **原文**（2026-04-16）：
  > "缩量不过新高，因为数据和昨天美股带起来的，危险系数不小的，做不好会死人。"

### 形态 5：日内量能拐头（日内操作信号）
- **特征**：分时量能从放大转为缩小（拐头向下）
- **含义**：日内行情接近尾声
- **操作**：不再追高，等待次日
- **原文**（2026-04-15）：
  > "量能拐头了。对，而且补了缺口了，今天日内差不多就这样了，不会杀了。"

### 形态 6：放量智障（2026-04-30 新增）
- **特征**：量能快速放大但价格不涨（盘口卖盘对冲）
- **含义**：资金不一致、有人在抛
- **操作**：白线主动下来则化解；否则警惕，防止转缩量
- **原文**（2026-04-30）：
  > "白线主动下来 化解了放量智障。"

### 形态 7：放量滞涨 = 高位换手（2026-05-11 新增）
- **特征**：日 K 放量但收盘没明显涨幅
- **含义**：高位机构在和接盘资金交换筹码
- **跌不跌**：取决于后续进场资金是否充足；4197 后突发利空导致后续不足 → 回踩
- **原文**（2026-05-11）：
  > "你看一下高位这些PCB CPO的标 你不要看日内分时 你看一下日K 这些都是放量滞涨的，其实就是交换筹码了 跌不跌取决于后续进场资金是否充足。"

### 形态 8：底背离 / 5 分钟波浪（2026-04 新增）
- **特征**：日内 5 分钟 K 出现底背离 + 5 浪结构走完
- **含义**：底背离至少有反抽，除非量化硬卖
- **操作**：盘中急杀完后等反抽 T 出
- **原文**（2026-04-02）：
  > "3916就是了 至少开始底背离 肯定有反抽的。除非量化硬卖。"
- **原文**（2026-04-09）：
  > "他走小的123 现在是2 我觉得目前不行 等2走完吧 创新药不是反制 他是极致缩量下的超跌反弹。市场一旦放量钱会先回科技。"

## 量能与行情阶段的对应关系

```
量能持续放大 → 3-3 主升浪，满仓轮动
量能温和放大 → 行情健康，正常持仓
量能放大转缩量 → 短期见顶，减仓
量能持续缩量 → 3-4 调整，等待
量能缩至冰点 → 底部形成，等放量确认
量能再次放大突破 → 3-5 二次加速，重新加仓
快速放量 + 突破 → 真突破
慢速放量 + 不涨 → 假突破 / 放量智障
放量滞涨 + 高位 → 换手派发
```

## 量能 + 板块共振原则

不要孤立看量能，要看**资金去了哪里**：
- 量能放大但只去战争板块 / 银保证 → 假突破
- 量能放大且去科技 / AI / 半导体 → 真突破
- 量能放大且券商护盘 + 银行护盘 → GJD 在场
- 量能放大但是金融、银保证拖累 → 不是反转位
