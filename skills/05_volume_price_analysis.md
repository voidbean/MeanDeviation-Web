# Skill 05：量价分析方法

## 概述

阿狼把**量能**当作判断行情最核心的指标，优先级高于价格本身：有量才有价，量能是资金行为的直接体现，量能变化先于价格变化。

本 skill 的方法论大部分属于**观点类**（形态定义、指标读法、判据结构），跨阶段可复用。但**量能的绝对数字必须绑定行情阶段读**——同一个"2WE"在 2026-07 指数 3800 时不算地量，在指数 4000 以上就是地量（2026-07-28）。因此下方「量能参考数值」表按阶段分层，每格都带日期和当时的盘面背景，取用时**先对齐阶段再对齐数字**。

## 量能核心原则

### 原则 1：有量才有价
放量＝有资金进场，行情可持续；缩量＝资金撤退。但在**下跌段**里缩量是好事：缩量才能磨底，没有缩量才是问题（2026-01-14）。

### 原则 2：放量速度 > 放量本身
真突破＝**快速放量**穿压力位且不缩回；假突破＝慢慢放量 → 高位"放量智障"（量上去价不涨）。放量之后要随时防止放量减缓转缩量（2026-04-30）。日内增量起来后，量能没有回退 1000E 以上，当天就不是高点（2026-04-08）。

### 原则 3：B 反看放量能否延续
B 反过程中**放转缩**→ 过不了 B 高 → 按 ABC 预期做（2026-05-21）。缩转放太早也会让 B 反更弱，因为拉起来就卖的资金太多（2026-05-15）。

### 原则 4：量能多一倍 = 当昨天没涨（见顶公式）
个股 / ETF 日 K 出现「放量跌破昨天红 K 最低价 + 量能多一倍」→ 视为昨天没涨；配合"不吃最后一根红 K"，当天即卖点，哪怕尾盘确认才卖也是对的（2026-05-21，半导体 ETF 案例）。

### 原则 5：撮合交易——没有卖盘时缩量也能上推
前一日放大量带上影线，把机构、柚子、散户的卖盘释放完，次日只剩买盘；上面没卖盘、下面不想追高，就只能缩量慢慢上推，技术派买一点指数就上去了（2026-06-15）。散户的量反而出在"跌了很久、才反弹一到两根 K 线"的方向。

⚠️ 缩量上涨**不是定式**：同一种盘面会有不同结果，要联系上下文看联动，重点是解读对上主力资金的想法，不要死背公式（2026-06-16）。

### 原则 6：地量的双重含义 + 相对化判定
- 地量不仅证明没人抄底，**也证明再跌也没人割肉了**，所以是好事（2026-07-08）；缩量阴跌没成交，跌不深（2026-08-03）
- 没量光跳价格没用：砸盘不出量就拿不到筹码，得不到结果的操作没人会做（2026-07-08）
- **地量必须与指数位置匹配**：指数 4000 以上 + 量能 2WE 以下才叫地量；指数 3800 时 2WE 只是量能配合指数，不存在"负地量"（2026-07-28）

### 原则 7：判定口径与换手率
- 看放量缩量要用同花顺里"对应前一天同期的量能比较"，而不是看分时量能天然的 U 型（2026-08-05）
- 换手率高说明没那么多能砸的筹码，跳也跳不出能接盘的位置（2026-08-04）；但高位筹码不断换手，这里就不一定是基石了（2026-06-17）

### 原则 8：主力"主动"的时候是缩量的时候
看盘不要想主力在很主动地做什么——主动的时候已经过去了，就是缩量的时候；放量之后都是顺势而为，因为手握主动权（2026-06-22）。

### 跌破关键位的恐慌盘量能机制（2026-06-11 历史案例）

```
跌破 3955 → 出大量恐慌盘 → 触发量化卖盘
  → 缩量 2000E 快速转放量 1000E（割肉盘平铺进场）
  → 因为都是割肉盘，买什么都能吃差价 → 普反
不破 3955 → 恐慌盘少、量化卖盘没触发
  → 场外 1000E 最多净流入 300E → 只去当日红的+有小作文的确定性方向
  → 下午缓慢放量 → 抱团细分反弹
```

## 白线 / 黄线指标

基础读法：
- **黄线在上**：大盘资金净流入（大资金主导）
- **白线在上**：小盘/个股资金活跃，大盘资金相对弱；白线在上时"涨的大部分都是老登"（2026-02-04）
- **低开 + 缩量 + 黄穿白**：确认性买点组合（2026-01-21）
- **白线在上 + 银保证还在杀**：肯定不可能是反转位；白线在上没法派发（2026-04-09）

### 进阶判断（2026-04-30）
- **白线主动下来＝化解放量智障**：散户没大量进场，资金切换没完成 → 行情还不能结束
- **黄线迅速下穿白线 + 大幅放量**：停止一切加仓并逢高抛售（2026-04-29 楼友总结，阿狼背书）
- **黄白线交织缩大量** / **白线快速上穿黄线缩量**：谨慎，不加仓

### 含义演化：看盘重心转向白线（2026-06-05）
缩圈阶段黄白线的指向变了：**黄线更多代表微盘**——散户也关注不到的票和当日细分题材，筑底时恐慌盘甚至出在黄线里；**白线更代表核心**，所以看盘重心转向白线。

### 长级别反弹段（X-4）里的黄白线用法
- **黄穿白行情**（2026-08-07）：高位切低位的动作完成后，行情按黄穿白去走，**越缩量越这么走**
- **白线连高点都不过**（2026-08-13）：量也放了、券商也动了，但白线不过高点 → 高点肯定有问题
- **冲击压力位时放转缩量 + 券商和科技都没涨 + 靠银行拉 + 微小题材拉升**（2026-08-10）→ 不买，但凡买就是被套

## 量价形态识别

| 形态 | 特征 | 含义 / 操作 | 出处 |
|------|------|-------------|------|
| 缩量磨底 | 量能萎缩至冰点，价格在支撑位小幅震荡 | 卖盘枯竭，等放量确认后介入 | 2026-01-14 |
| 放量突破 | 量能突放 + 有效破关键压力位 | 大资金进场，尾盘确认后跟进 | 2026-04-08 |
| 缩量反弹 | 价格反弹但量能没跟上 | 没有增量，不追高；过不过新高都减仓 | 2026-01-14 |
| 放量不过新高 | 量放大但价格上不去前高 | 上方压力大，危险系数不小 | 2026-04-16 |
| 日内量能拐头 | 分时量能由放转缩 | 日内接近尾声，不再追高 | 2026-04-15 |
| 放量智障 | 量快速放大但价格不涨 | 白线主动下来则化解；否则防转缩量 | 2026-04-30 |
| 放量滞涨 | 日 K 放量但收盘没涨幅 | 高位换手交换筹码；跌不跌取决于后续进场资金是否充足 | 2026-05-11 |
| 底背离 + 5 分钟波浪 | 日内 5 分钟底背离 + 5 浪走完 | 至少有反抽，除非量化硬卖 | 2026-04-02 |
| 缩转放后 ABC | 急杀 → 缩量企稳 → 转放 → 反弹 → 顶分型 → 再下杀 | 到 BOLL 中轨或半分位就 T 出；缩转放太早则 B 反更弱 | 2026-05-15 |
| B 反接 C 杀 | 早盘 B 反 → 13:30 后突转放量直打 C 区 | 罕见，恐慌盘一把打出 2 个价位；先降仓位 | 2026-05-21 |

| 吃货后缩量拉起 | 尾盘放量吃掉割肉筹码 → 次日缩量拉起 | 看散户追不追：不追就横在上面等，追了就送给你再来一次 | 2026-08-04 |

| 持续放量下的反抽 | 已经持续放量的滞涨/回落段里的反抽 | 只是一分钟级别，没意义 | 2026-08-18 |

### 午后跳水判别树（2026-08-18）

```
现在：缩量 + 用银行拉指数
├─ 银行跳水 + 不放量        → 没事
├─ 银行继续拉 + 科技跳水 + 放量 → 很有大事
└─ 缩量又转放量              → 就能看见跳水
```

## 揉搓线 8 种形态全表（2026-06-02 教学）

揉搓线 = 一根 K 线同时带明显上影和下影。按**趋势方向 × K 线颜色 × 上下影顺序**分 8 种（阿狼原话："这些不是一定出现，算大概率吧"）：

| 趋势 | K 线 | 影线顺序 | 含义 |
|------|------|----------|------|
| 下跌趋势 | 黑 K | 下影接上影 | **中继下跌** |
| 下跌趋势 | 红 K | 下影接上影 | **支撑位震荡选方向** |
| 下跌趋势 | 红 K | 上影接下影 | **支撑位资金抢反弹** |
| 下跌趋势 | 黑 K | 上影接下影 | **短期止跌** |
| 上涨趋势 | 黑 K | 下影接上影 | **开始有分歧** |
| 上涨趋势 | 红 K | 下影接上影 | **分歧但强势，继续看新高** |
| 上涨趋势 | 红 K | 上影接下影 | **承接力度大，但只承接不追高** |
| 上涨趋势 | 黑 K | 上影接下影 | **承接低，可能出现短期顶** |

**使用要点**：最好配合量能看；还要看上下影的长度判断力度；这是"浅显"的经验规律，不是死板公式。配合 [[03_entry_exit_signals]] 的红色揉搓线缩量止跌信号与揉搓线见顶组合使用。

> "中午没事干 分享个技术指标吧 揉搓线你们会不会看 我说一下我的操作体系里关于揉搓线的用法吧 这些不是一定出现，算大概率吧 下跌趋势 黑K下影接上影 ---中继下跌 下跌趋势 红K下影接上影 ---支撑位震荡选方向 下跌趋势 红K上影接下影 ---支撑位资金抢反弹 下跌趋势 黑K上影接下影 ---短期止跌 上涨趋势 黑K下影接上影 --- 开始有分歧 上涨趋势 红K下影接上影 ---分歧但强势继续看新高 上涨趋势 红K上影接下影 ---承接力度大 但是只承接不追高 上涨趋势 黑K上影接下影 ---承接低可能出现短期顶 当然最好配合量能看，而且还要看上下影的长度判断力度。不过经验就是这样了。浅显的你们了解一下就行。" —— 2026-06-02

## BOLL 中轨判断市场强弱（2026-05-22）

- 日分时**回到** BOLL 中轨以上 → 市场偏强
- 日分时**回不到** BOLL 中轨以上 → 市场偏弱
- 用于"放量下跌后能否高看一眼"的辅助判断，也是缩转放 ABC 结构里的 T 出参考位

## 反弹 vs 反转的量能判据（2026-08-17）

- **只要没有放量冲破半分位，那都是反弹，不是反转**——是反弹就不该有高预期
- 反弹幅度分三档：**强**＝半分位上方一点；**平均**（大部分）＝和指数差不多；**弱**＝仅仅止跌横盘
- 操作目标：选到**平均值**的票，通过超额操作吃到**强**那个档次的涨幅
- 事后统计（2026-08-18）：大部分科技平均反弹到 0.618 位置，弱的一部分、强的更少一部分，完全符合波浪理论

## 量化主卖识别（2026-05-21 复盘）

- **典型时段**：下午 13:30 ~ 14:00（新规前是 13:00~14:30，新规后窄一些）
- **特征**：午盘后分时缩量震荡 → 突然由缩转放 → 持续放量主卖
- **强度参考**：5-21 半小时打掉 4140 → 4067（73 个指数点），打到 60 日线附近
- **历史相似**：3 月每天 10 点后的量化主卖，这次更急
- **应对**：盘中**无法预判**，控制仓位是唯一办法

## 量能 + 板块共振原则

不要孤立看量能，要看**资金去了哪里**：
- 量能放大但只去战争板块 / 银保证 → 假突破
- 量能放大且去科技 / AI / 半导体 → 真突破
- 量能放大 + 券商护盘 + 银行护盘 → GJD 在场
- 量能放大但金融、银保证拖累 → 不是反转位
- **今天涨没有轮动**（早盘 1 小时内全部启动，没有"完成 → 接力"）= 不能高看（2026-05-22）
- **科技吸血全市场**、无任何方向能接力 → 普跌的根本原因（2026-05-21）
- 量能被单个高位板块吃掉时，同级别板块之间是**竞争**关系（2026-08-05：国产半导体 vs 海外光）

## 期指与资金流向辅助

### 期指量能
- 期指多单占优 → 机构看多，次日大概率上涨
- 期指空单猛加 → 机构看空，注意风险
- 上证 50 / 沪深 300 空单占优 → GJD 可能在打压宽基，但不针对科技
- **数据严谨性**：看错数据条件就错了（2026-01-22）

### 南向资金
- 单日 +100E 以上时次日上证胜率高（2026-04 当月 6/6，涨幅 ≥ 0.8%）
- 单日卖出快 100E → 大概率次日冲高回落，然后调整两三天（2026-05-06）

### 两融余额
- 持续增加 → 场外资金进场；大幅缩水 → 杠杆资金出逃
- 数据是 T+1 的，次日 9 点左右才能看到（2026-05-21）
- 2026-05-13 阿狼给出的两融压力位是 3.2（当时未到）；两融跑掉的钱后面也是要回来的（2026-08-05）
