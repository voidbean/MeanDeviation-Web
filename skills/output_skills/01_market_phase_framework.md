# Skill 01：行情阶段划分框架

## 概述

阿狼使用自创的"3-X"阶段体系来描述A股大盘所处的行情阶段，并据此决定仓位和操作策略。该体系以上证指数的技术形态、量能变化和资金行为为判断依据。

在 3-4 调整期内部，阿狼还会进一步细分出"**机构自救行情**"、"**绞肉机行情**"等子形态——同样是调整，但操作逻辑完全不同。

进入 3-5 加速阶段后（2026-05），阿狼又给出了**ABC 微调结构（B 反 + C 杀）**、**加速段虹吸效应**、**衰竭浪诱多本质**等更细颗粒度的判断方法。

5 月底 C 杀落地后（2026-05-28 ~ 2026-06），行情转入 **C 缓跌 + 震荡筑底**阶段。阿狼进一步给出了 **C 缓跌结尾形态**、**震荡筑底找底逻辑（看谁新进场，不看跌到哪）**、**3955 关键点位决策（破=普反 / 不破=抱团细分反弹）**、**大 4 浪 vs 下跌一浪的区分**等判断方法。

## 阶段定义

### 3-1：底部确认阶段（磨底期）
- **特征**：指数在低位震荡，量能持续萎缩，无明显方向
- **操作**：轻仓观望，等待确认信号，不主动加仓
- **关键信号**：日线级别出现 W 底形态 + 红三兵

### 3-2：突破确认阶段（启动期）
- **特征**：指数突破关键颈线位，量能开始放大，红三兵确认
- **操作**：逐步建仓，买入主线题材
- **结束确认条件**：日线 W 底后红三兵 → 突破颈线加速 → 关键点位（如 4006）站稳三天后量能暴涨
- **原文**（2026-01-12）：
  > "3-2 的结束确认条件是什么：日线级别 W 底后的红三兵表现，突破颈线的加速，4006 站稳三天后量能的暴涨，吃技术流和踏空资金的进场溢价，这些都是一步步来的。"

### 3-3：主升浪阶段（加速期）
- **特征**：量能持续放大，主线题材加速上涨，踏空资金不断涌入
- **操作**：满仓轮动（75% 以上），主升加速浪不言顶
- **第一阶段目标区间**（本轮）：4317–4375
  - **点位来源澄清（2026-06-04）**：阿狼原话一直是 **4317-4375**（不是流传的"4315"），且强调"不要只看数字，要知道这些数字怎么来的"——物理顶 4317 来自上一年 12 月 W 底测算，情绪顶可能更高，所以给区间
- **结束信号**：放量转缩量 + 收黑 K 跌破 5 日线 → 短期见顶，减仓避险
- **原文**（2026-01-12）：
  > "主升加速浪开启不言顶。接盘的量不够了就会调整，那就是放量转缩量，收黑 K 跌破 5 日线那就是短期见顶，而且只是短期，到时候减仓避一下就行。"

### 3-4：调整阶段（震荡期）
- **特征**：量能萎缩，指数在关键支撑位附近震荡，主线题材退潮
- **操作**：降至 50% 仓位，减少操作，以持仓等待为主；做低位 T
- **原文**（2026-01-21 前后）：
  > "控制仓位，减少操作，持仓等，在回暖前预期低一点。"

### 3-5：趋势延续 / 二次加速阶段
- **特征**：调整结束后再次放量突破，形成新一轮主升
- **操作**：重新加仓至 75% 以上
- **注意**：3-3 和 3-5 的资金会在关键点位发生剧烈多空博弈
- **加速段铁律**：**加速期不会换主线**（2026-05-12）

## 3-5 加速阶段微结构（2026-05 新增）

3-5 行情进入末段后，阿狼把指数的微观运动拆成"小 ABC"：
- **A 浪**：主升加速段（典型 4140 → 4258 大涨）
- **B 反**：技术回踩后的反弹（看到二卖位附近）
- **C 杀**：B 反结束后的二次下跌（量化主导，速度极快）

### B 反 / C 杀 标准节奏（2026-05-19 → 2026-05-22 案例）
- 5-12 ~ 5-13 A 浪冲到 4258 附近见顶
- 5-14 ~ 5-15 走 B 反，理论目标"昨天二卖位附近 4210"
- 5-19 ~ 5-20 反复磨顶
- 5-21 出现**罕见结构**：B 反结束当天直接打到 C 区域 4067
- 5-22 反弹补量化主卖部分，等待是否补完 4140 决定 C 是否结束

### B 反弱 / 强的判断（2026-05-15）
- B 反高点正常应到 **昨天二卖位附近**（不是当天最高点）
- **B 反弱的主因**：缩转放太早 → 拉起来的科技卖的资金太多 → 当天切不光
- **解决办法**：用垃圾板块（白酒、光伏）诱多，给低位资金接盘机会
- **原文**（2026-05-15）：
  > "今天B反为什么弱 因为缩转放太早了 也就是 拉起来的科技卖的资金太多了 是 太多了 巨多……然后一旦出个什么光伏 就和那天白酒一样 招呼大家换方向了。"

### C 杀的两种走法
1. **标准 C 杀**：B 反结束后慢慢下，磨出底部结构后才止跌
2. **非标 C 杀**（5-21 出现）：B 反当天直接跳到 C 区域，"B 反接 C 杀我确实没见过 恐慌盘被打了2个价位出来"
- **C 浪结束依据**：**看结构，不看点位**（"区间在日 K 的 60 线 但是能不能结束主要是看结构"，2026-05-21）

### 缺口规则
- **启动缺口（下方）不能补**：补了这里就是最高点（本轮约 3674-3700 一带）
- **衰竭缺口（上方）需要补**：补完后机构就少一个技术麻烦点；本轮已补两个
- **原文**（2026-05-15）：
  > "下面是启动缺口 不能补的 补了这里就是最高点 所以现在是补了后面两个衰竭缺口 我觉得差不多了。"

## 3-5 末段两个核心机制（2026-05 新增）

### 机制 1：加速虹吸效应
- 当全市场量能 < 3.5W 亿时，主升核心票每涨 1 个点 ≈ 50 只小票跌 1 个点
- 加速段中**所有非核心科技板块的资金会被吸进半导体**
- 低位非核心科技反而更危险（早卖的没补、晚卖的被套）
- **原文**（2026-05-15）：
  > "加速阶段的虹吸效应 只要都是3.5WE以下 中继旭创涨一个点是不是代表50只小票跌1个点？"

### 机制 2：衰竭浪 = 多次诱多
- 衰竭浪**不是一次诱多**，而是**多次诱多**，目的是把散户挂到山顶
- 每次诱多后都会再下杀一次，"反复挨打"
- 散户的循环：早盘割肉 → 下午追回 → 第二天再被摁
- **原文**（2026-05-14）：
  > "衰竭浪就是多次诱多 最后把散户挂山顶。"
  > "昨天下午就是了 今天会不断的补仓。我都不用猜 然后等下跌破缺口的时候他们会把昨天的割肉出去 那个时候我再考虑要不要吃他们的肉 做第二次诱多。"

## 3-5 末段防御机制：不会全面拉防御

- 3-5 末段（非最终顶）：拉防御**只会拉单一板块**（如白酒 / 光伏），让低位资金被诱进去
- 真正全面防御（白酒+消费+医药+电力同时拉）= 才是最后顶点信号
- 拉单一防御板块后科技仍会再涨一波，散户会忍不住割低位防御去追科技
- **原文**（2026-05-14）：
  > "如果拉防御有用 就不会只拉白酒消费 这里因为不是最后顶点。所以不会全面防御的。"
  > "一旦有新进老登 去追了防御 你就会看见科技又反弹了 这两天你就能看到 要让他们死死套在这些所谓的防御里面 实在最后忍不住情绪最崩溃的时候 去追最高位的科技。"

## C 缓跌结尾 与 震荡筑底阶段（2026-05-28 ~ 2026-06 新增）

C 杀落地后并非立刻反转，而是先走 **C 缓跌**，再进入 **震荡筑底**。这一段是 3-5 末段杀跌后、决定能否再起一波（接 4317-4375）的关键观察期。

### C 缓跌的结尾形态（2026-05-26）
- **定义**：C 缓跌的结尾，一定是在「不破大盘 60 日线，或破一下当天拉回」的前提下，**某一天一根阳线突破下跌通道**才算结束
- 在此之前的反弹都只是「C 缓跌中的反抽」，不是结束
- **短期技术节点时效极短**：盘中算出的反抽点位"只管到明天 10 点半"，多的涨幅"不关我的事，预判不出来"
- **原文**（2026-05-26）：
  > "C的缓跌 结尾一定是不破大盘60日线或者破一下当天拉回的前提下，某一天一根阳线突破下跌通道。 现在是C缓跌中的反抽 所以我说管到明天早上 这是很细节的技术。"

### 震荡筑底阶段（2026-05-28 起）
- C 缓跌反抽走完后，"接下来开启震荡底"
- **找底的核心逻辑（反直觉）**：找到指数底"没什么用"，关键不是"跌到哪里"，而是"**谁会新进场，他们做哪个方向**"
- **没出恐慌盘 = 没有新增量承接**：缩量没有恐慌盘，意味着场外资金不会进来接；"A 股不好做空，买进去要能涨才行，不跌没 P 用"
- **半导体是总开关**：半导体不止跌，整个市场都不会好；别的方向都只是"超跌轮动 / 搅动市场"，没有持续性
- **原文**（2026-06-01）：
  > "找到指数底没什么用啊 资金太乱了 主要是半导体还没止跌。 整个市场都不会好。"
- **原文**（2026-06-08）：
  > "没出恐慌盘那就意味着没有新进增量承接的可能 现在不是考虑跌到哪里的问题 而是考虑谁会新进场 他们做哪个方向。"
- **原文**（2026-06-05）：
  > "首先 行情还在筑底阶段……目前就是震荡筑底阶段。"

### 3955 关键点位决策（2026-06-11）
震荡筑底期，3955 是决定后续走势性质的分水岭：
- **跌破 3955** → 出大量恐慌盘 → 触发量化卖盘 → 缩量 2000E 快速转放量 → 场外约 1000E 平铺进场吃割肉差价 → **普反**（普涨反弹）
- **不破 3955** → 恐慌盘少、量化卖盘没触发 → 场外资金最多净流入约 300E → 只去当日红的 + 有小作文的确定性方向 → **抱团细分反弹**（缩圈）
- 级别顺序：破位先看**反抽**（不是反弹、更不是反转）；"级别都是从小到大的"
- **原文**（2026-06-11）：
  > "本来场外有1000E要进场 如果跌破3955 出大量恐慌盘，就会快速从缩量2000E转成放量1000E 这1000E会平铺进场 因为都是割肉盘 买什么都能吃差价 现在没跌破 出的恐慌盘少……那1000E最多净流入300E，所以你看下午就是缓慢放量。"
  > "破了会有普反 没破就是抱团细分反弹。"

### 高/低开当日策略锚点（2026-06-12）
- 早上开盘高/低决定当天用哪套预案，不需要再纠结点位："今天铁高开啊 这还用问的？高开那肯定用高开的策略"
- 不复盘做计划"大盘涨跌真的和你们没关系"

## 3-4 内部子形态（2026 年 3–4 月新增）

### 子形态 A：绞肉机行情（3900 ± 50 点）
- **特征**：指数在窄区间（如 3870–3955）反复震荡，没有趋势、没有主线、没有持续性，量能时大时小
- **场景**：3-4 调整中没有新增量、纯存量资金博弈的过程
- **操作**：激进策略 4–6 层仓位区间做 T，越接近下沿（3870-3900）加仓越凶；不会做 T 的直接降到 30% 等关键时间窗口
- **原文**（2026-03-27 → 2026-04 反复重申）：
  > "这里没有趋势 没有主线 没有持续性……我选择这里不做。目前43%仓位，忍到下个月16号之后。" —— 2026-03-27
  > "3900绞肉机策略就是激进的……可以4层仓位加到6层，明天T出回到4层。" —— 2026-04-02
  > "绞肉机行情挣钱有多难。" —— 2026-04-02
- **退出**：放量突破上沿后转 B 反（见 3-5 / B 反）；放量跌破下沿则触发深度调整

### 子形态 B：机构自救行情（高切低，无普涨）
- **特征**：指数缓慢爬升或横盘，但**没有普涨**，机构在板块之间不断高切低，每日只有少数板块在涨
- **本质**：机构被金融板块砸盘后成本变高，**通过低位轮动吸引散户接盘自救**，不是国家队也不是新增量行情
- **判断方法**：观察是否只有结构性抱团，没有普涨；当日跌停家数明显减少
- **原文**（2026-04-14 → 2026-04-16）：
  > "机构结构性抱团自救 所以我说这里是机构最舒适的区域……全市场应该只有我第一个判断出来是机构自救行情。" —— 2026-04-14
  > "只有国家队才有普涨 机构只会结构性抱团。" —— 2026-04-14
  > "机构行情和柚子情绪行情不一样，柚子行情是一段不回调的龙头抱团……机构行情大部分时候不会这样，而是利用网格差价每天挣一点。" —— 2026-04-14
- **配套仓位**：50% 底仓 + 30% 日内 / 1–2 天 T + 20% 应对黑天鹅抄底
- **结束信号**：GJD 主动进场（普涨出现）→ 进入新一轮主升 / B 反

### 子形态 C：B 反（B 浪反弹）
- **特征**：在 ABC 调整中的反弹段，量能能放就能涨，缩量易出顶
- **判断**：除非新高，不然无法判断反转；目前是 B 反过程
- **目标区间**：3955 一卖 → 4020 二卖 → 4030–4035（4.13 更新）→ 4100–4096（4.20 更新）→ 4114 / 4197（4.29-5.11 实际触达）
- **原文**（2026-04-08 / 2026-04-20）：
  > "之前大盘在跌的时候我说继续看3955一卖位 4020二卖位 在昨天晚上以前你们甚至不敢想吧。" —— 2026-04-08
  > "除非新高 不然目前看不到反转的可能 现在是B反过程 只不过有量目前就不是高点 缩量就容易出高点。" —— 2026-04-20

### 子形态 D：弱 C / 强 C（ABC 之 C 浪）
- **概念**：ABC 结构中 A 长则 C 短、A 短则 C 长；强势盘面 C 不会比 A 低（除非黑天鹅利空）
- **应用**：选股时优先选 A 长 C 短的板块（更安全）
- **原文**（2026-04-19）：
  > "ABC结构里面 再大盘的一段行情中，下跌的票大概率都是一样的长度，那A长C就短，A短C就长……肯定选择A长C短的更为安全。"

## 阶段判断决策树

```
观察当前大盘：
1. 量能是否持续放大？
   - 是 → 进入 3-3 或 3-5 判断
   - 否（缩量）→ 进入 3-1 或 3-4 判断

2. 是否突破关键颈线/前高？
   - 是 + 放量 → 3-2 确认 / 3-3 开启
   - 否 → 3-1 磨底或 3-4 调整

3. 在 3-4 内部：
   - 窄区间反复震荡，无趋势 → 绞肉机行情（区间 T）
   - 结构性高切低，无普涨 → 机构自救行情（持仓+轮动）
   - 反弹但未新高 → B 反（看一卖二卖位）

4. 在 3-5 内部：
   - A 浪加速中，主线虹吸 → 持仓不追，正 T 为主
   - A 浪结束（缩量不过新高 / 衰竭缺口）→ 进入 ABC 微调
   - B 反中（量价配合）→ 反弹至二卖位 T 出
   - C 杀中（结构未磨够）→ 不抄底，等结构出来
   - 拉单一防御 = 还不是最后顶；全面拉防御 = 顶

5. 主线题材是否在加速？
   - 是 → 3-3 / 3-5 主升浪，满仓轮动
   - 否 → 3-4 调整，降仓等待
   - 注意：加速期不换主线，不要因短期回撤就换车

6. 是否出现放量转缩量 + 黑 K 破 5 日线 / 量能多一倍跌破昨天红K？
   - 是 → 短期见顶，减仓至 50-60%

7. GJD 是否主动进场（普涨 + 银行护盘）？
   - 是 → 准备从机构自救切换到新一轮 B 反 / 主升
   - 否 + 3-5 阶段 → 机构主导，GJD 不再控盘
```
