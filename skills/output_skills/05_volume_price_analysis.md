# Skill 05：量价分析方法

## 概述

阿狼将**量能**视为判断行情最核心的指标，优先级高于价格本身。核心逻辑：**有量才有价，量能是资金行为的直接体现，量能变化先于价格变化。**

2026-04 月起，阿狼新增了"**放量智障**"、"**白线主动下行化解智障**"、"**8000E 增量底线**"等更细颗粒度的盘口判读方法。

2026-05 月进入 3-5 末段后，进一步新增：
- **"量能多一倍 = 当昨天没涨"**（5-21 半导体见顶判断公式）
- **"3000E 量化离场可识别"**（5-22 缩量原因量化）
- **BOLL 中轨判断市场强弱**
- **量能 + 板块轮动共振原则**：今天涨没有轮动 = 不能高看

2026-06 震荡筑底阶段又补充：
- **揉搓线 8 种形态全表**（6-02 教学）
- **黄线/白线含义演化**：黄线现在更多代表微盘/细分题材，白线代表核心（看盘重心转向白线）
- **跌破 3955 缩量 2000E 转放量 1000E 恐慌盘机制**

## 量能核心原则

### 原则 1：量能决定行情能否持续
- 放量 = 有资金进场，行情可持续
- 缩量 = 资金撤退，行情无法持续
- **原文**（2026-01-12）：
  > "有量就有价。"

### 原则 2：量能阈值判断
| 量能水平 | 含义 | 操作 |
|---------|------|------|
| 持续放量（> 前日）| 主升浪，资金持续涌入 | 持仓或加仓 |
| 温和放量 | 行情健康，可以操作 | 正常持仓 |
| 缩量（< 前日 30%）| 行情走弱，等待 | 减少操作，观察 |
| 缩量 7000 亿以下 | 高标出不来，不追 | 不操作 |
| 缩量 1 万亿以下 | 市场无法上涨 | 不操作 |
| 量化离场缩量（约 3000E 资金）| 大资金站场外看 | 警惕，不追涨 |

**原文**（2026-01-15）：
> "缩量 7000E，这么快的缩量高标出不来的，所以暂时不要去，等他们回暖那一下可以去抢抢反抽。"

**原文**（2026-01-16）：
> "缩量快 1WE，哪里能上去，用膝盖想都懂了。"

**原文**（2026-05-22）：
> "因为缩量 至少3000E资金包括量化今天光站在场外看了。"

### 原则 3：放量转缩量是见顶信号
- 主升浪中：放量转缩量 + 黑 K 破 5 日线 = 短期见顶
- 调整中：缩量才能止跌，缩量是好事
- **原文**（2026-01-15）：
  > "最主要是量能，没有缩量，这才是问题，放量就必须快速拉上去，缩量才能磨底。"

### 原则 4：放量速度比放量本身更重要（2026-04-30 新增）
- 真突破：**快速放量**穿压力位 + 不缩回
- 假突破：慢慢放量 → 高位"放量智障"（量上去价不涨）
- **原文**（2026-04-30）：
  > "没有速度 放量智障 而且是快速放量 这里不卖 但是谨慎 随时防止放量减缓转缩量。"

### 原则 5：放量回退 1000E 才算高点（2026-04-08 新增）
- 当天 8000E 增量起来后，回退 1000E 以上才能确认日内高点
- 没回退 1000E 不要急着卖
- **原文**（2026-04-08）：
  > "我都和你说了 现在看什么 看量能 量能没有回退1000E以上今天就不是高点。"

### 原则 6：缩量调整 = 健康（2026-04-21 新增）
- 缩量调整 ≠ 行情结束
- 关键看是否在支撑位附近止跌
- **缩量涨没有危险**（2026-05-15）"缩量涨有什么危险的"
- **原文**（2026-04-21）：
  > "缩量调整啊。"
- **原文**（2026-05-15）：
  > "缩量涨有什么危险的。"

### 原则 7：B 反看放量过 B 高（2026-05-21 新增）
- B 反过程中：**放转缩 → 过不了 B 高 → 按 ABC 预期做**
- 也就是说，B 反想要继续延伸，必须维持放量；放转缩就该卖
- **原文**（2026-05-21）：
  > "放转缩 那就过不了B高 按之前的ABC预期做。"

### 原则 8：量能多一倍 = 当昨天没涨（2026-05-21 新增，半导体见顶公式）
- 个股 / ETF 日 K 出现「**放量跌破昨天红 K 最低价 + 量能多一倍**」→ 视为"昨天没涨"
- 配合"不吃最后一根红 K" → 当天就是卖点
- 哪怕尾盘确认才卖，也是对的
- **原文**（2026-05-21）：
  > "半导体ETF今天就是卖点了 哪怕尾盘确认的时候卖也是对的 符合我之前分享过的 不吃最后一根红K 今天放量跌破昨天的红K 量能多一倍 就当昨天没涨就行了。"

## 白线 / 黄线指标

阿狼频繁提到"白线"和"黄线"，这是他用来判断大盘资金流向的核心工具：
- **黄线在上**：大盘资金净流入（大资金主导），是加仓信号
- **白线在上**：小盘/个股资金活跃，大盘资金相对弱
- **黄白一起拉上去**：最强信号，可以满仓操作

**原文**（2026-02-04）：
> "其实今天白线全天在上，涨的大部分都是老登，你们买不对票肯定赢不了的，买对票，这个才是重点。"

**原文**（2026-02-05）：
> "低开，缩量，然后黄穿白，你们说符合什么。"（答：确认性买点）

### 黄白线进阶判断（2026-04-30 新增）
- **白线主动下来 = 化解放量智障**：散户没大量进场，资金切换没完成 → 行情还能继续
- **黄线下穿白线 + 大幅放量 = 顶部信号**：必须立即停止加仓 + 逢高减仓
- **黄白线交织缩大量** / **白线快速上穿黄线缩量**：谨慎，不要加仓

**原文**（2026-04-30）：
> "白线主动下来 化解了放量智障 证明进来的散户不够多 目前切换不完 行情还不能结束。"

**原文**（2026-04-29 楼友总结，阿狼背书）：
> "黄线迅速下穿白线且伴随大幅放量时，停止一切加仓并逢高抛售个股的动作。"

**原文**（2026-04-09）：
> "白线在上怎么派发 你会买吗 我肯定不买啊。"
> "今天白线在上 银保证还在杀 证明这里肯定不可能是反转位。"

### 黄白线 5-12 ~ 5-22 案例
- **5-12 早盘 11:07**：大盘黄线在下、缩量、高开低走再次冲击前高 4230 → 阿狼当天减仓到 70%
- **5-14 全天**：黄线在下 + 放量 → "全天没有任何买点"
- **5-20 早盘**：白线在上 + 放量 → 各种金属类临界点跳水
- **5-21 顶级诱多识别**：缩量 + 白线在上 + 过开盘点 = 顶级诱多走势（卖点）
- **5-21 黄线打到昨天量化杀盘起点**：换手区域，T 出去不算错

### 黄白线含义演化：看盘重心转向白线（2026-06-05 新增，重要）
震荡筑底 + 缩圈阶段，黄白线的指向发生变化，阿狼明确**看盘重心从黄线转向白线**：
- **黄线现在更多代表微盘**——那种散户也关注不到的票和当日细分题材；筑底时恐慌盘甚至出在黄线里
- **白线更代表核心**——所以现在更关注白线
- 这是因为缩圈下资金集中到核心，微盘/细分被边缘化，黄线翻红常常是"散户也关注不到的题材"在动，不代表核心强
- **原文**（2026-06-05）：
  > "后面看到黄线上穿也不觉得有问题么 现在黄线更多代表微盘 就是那种散户也关注不到的票和当日细分题材 我现在更关注白线。"

### 跌破 3955 的恐慌盘量能机制（2026-06-11 新增）
缩量筑底时，关键点位（3955）决定量能如何释放，进而决定后续走势：
```
跌破 3955 → 出大量恐慌盘 → 触发量化卖盘
  → 缩量 2000E 快速转放量 1000E（割肉盘平铺进场）
  → 因为都是割肉盘，买什么都能吃差价 → 普反
不破 3955 → 恐慌盘少、量化卖盘没触发
  → 场外 1000E 最多净流入 300E → 只去当日红的+有小作文的确定性方向
  → 下午缓慢放量 → 抱团细分反弹
```
- 这条把"量能"和 [[01_market_phase_framework]] 的 3955 决策、[[08_market_participants]] 的恐慌盘逻辑串起来
- **原文**（2026-06-11）：
  > "如果跌破3955 出大量恐慌盘，就会快速从缩量2000E转成放量1000E 这1000E会平铺进场 因为都是割肉盘 买什么都能吃差价 现在没跌破 出的恐慌盘少……那1000E最多净流入300E，所以你看下午就是缓慢放量。"

## 量价形态识别

### 形态 1：缩量磨底（底部信号）
- **特征**：量能持续萎缩至冰点，价格在支撑位附近小幅震荡
- **含义**：卖盘枯竭，底部形成中
- **操作**：等待放量确认后介入

### 形态 2：放量突破（启动信号）
- **特征**：量能突然放大 + 价格有效突破关键压力位
- **含义**：大资金进场，行情启动
- **操作**：跟进，尾盘确认后买入
- **2026-04-08 标志日**：8000E 增量 + 跳空 3930 起来 = 这些资金的成本底线

### 形态 3：缩量反弹（虚假反弹）
- **特征**：价格反弹但量能未跟上
- **含义**：没有增量资金，反弹不可持续
- **操作**：减仓，不追高
- **原文**（2026-01-14）：
  > "缩量反弹，今天过不过新高我都会减仓。"

### 形态 4：放量不过新高（顶部信号）
- **特征**：量能放大但价格无法突破前高
- **含义**：上方压力大，主力出货
- **操作**：减仓
- **原文**（2026-04-16）：
  > "缩量不过新高，因为数据和昨天美股带起来的，危险系数不小的，做不好会死人。"

### 形态 5：日内量能拐头（日内操作信号）
- **特征**：分时量能从放大转为缩小（拐头向下）
- **含义**：日内行情接近尾声
- **操作**：不再追高，等待次日
- **原文**（2026-04-15）：
  > "量能拐头了。对，而且补了缺口了，今天日内差不多就这样了，不会杀了。"

### 形态 6：放量智障（2026-04-30 新增）
- **特征**：量能快速放大但价格不涨（盘口卖盘对冲）
- **含义**：资金不一致、有人在抛
- **操作**：白线主动下来则化解；否则警惕，防止转缩量
- **原文**（2026-04-30）：
  > "白线主动下来 化解了放量智障。"

### 形态 7：放量滞涨 = 高位换手（2026-05-11 新增）
- **特征**：日 K 放量但收盘没明显涨幅
- **含义**：高位机构在和接盘资金交换筹码
- **跌不跌**：取决于后续进场资金是否充足；4197 后突发利空导致后续不足 → 回踩
- **原文**（2026-05-11）：
  > "你看一下高位这些PCB CPO的标 你不要看日内分时 你看一下日K 这些都是放量滞涨的，其实就是交换筹码了 跌不跌取决于后续进场资金是否充足。"

### 形态 8：底背离 / 5 分钟波浪（2026-04 新增）
- **特征**：日内 5 分钟 K 出现底背离 + 5 浪结构走完
- **含义**：底背离至少有反抽，除非量化硬卖
- **操作**：盘中急杀完后等反抽 T 出
- **原文**（2026-04-02）：
  > "3916就是了 至少开始底背离 肯定有反抽的。除非量化硬卖。"
- **原文**（2026-04-09）：
  > "他走小的123 现在是2 我觉得目前不行 等2走完吧 创新药不是反制 他是极致缩量下的超跌反弹。市场一旦放量钱会先回科技。"

### 形态 9：缩转放后 ABC（2026-05-15 新增）
- **特征**：早盘急杀 → 缩量企稳 → 突然转放 → 反弹 → 顶分型 → 再下杀
- **含义**：典型的 B 反短结构；缩转放太早会让 B 反更弱
- **操作**：到 BOLL 中轨或半分位附近就 T 出
- **原文**（2026-05-15）：
  > "今天B反为什么弱 因为缩转放太早了 也就是 拉起来的科技卖的资金太多了。"

### 形态 10：B 反接 C 杀（罕见，2026-05-21 新增）
- **特征**：早盘做 B 反 → 13:30 后突然转放量 → 直接打到 C 区域
- **含义**：恐慌盘"一把打出 2 个价位"——量化主卖
- **操作**：超预期，必须复盘后再决策；先把仓位降下来
- **原文**（2026-05-21）：
  > "B反接C杀这种走法我确实没见过 恐慌盘被打了2个价位出来。"

## 揉搓线 8 种形态全表（2026-06-02 教学新增）

揉搓线 = 一根 K 线同时带明显上影和下影（资金反复揉搓）。阿狼给出他操作体系里揉搓线的用法（"不是一定出现，算大概率"），按**趋势方向 × K 线颜色 × 上下影顺序**分 8 种：

| 趋势 | K 线 | 影线顺序 | 含义 |
|------|------|----------|------|
| 下跌趋势 | 黑 K | 下影接上影 | **中继下跌** |
| 下跌趋势 | 红 K | 下影接上影 | **支撑位震荡选方向** |
| 下跌趋势 | 红 K | 上影接下影 | **支撑位资金抢反弹** |
| 下跌趋势 | 黑 K | 上影接下影 | **短期止跌** |
| 上涨趋势 | 黑 K | 下影接上影 | **开始有分歧** |
| 上涨趋势 | 红 K | 下影接上影 | **分歧但强势，继续看新高** |
| 上涨趋势 | 红 K | 上影接下影 | **承接力度大，但只承接不追高** |
| 上涨趋势 | 黑 K | 上影接下影 | **承接低，可能出现短期顶** |

**使用要点**：
- 最好**配合量能**看
- 还要看**上下影的长度**判断力度
- 这是"浅显"的经验规律，了解即可，不是死板公式
- 配合 [[03_entry_exit_signals]] 信号 E（红色揉搓线缩量止跌）和卖出信号 17（揉搓线见顶组合）使用

**原文**（2026-06-02）：
> "下跌趋势 黑K下影接上影 ---中继下跌 下跌趋势 红K下影接上影 ---支撑位震荡选方向 下跌趋势 红K上影接下影 ---支撑位资金抢反弹 下跌趋势 黑K上影接下影 ---短期止跌 上涨趋势 黑K下影接上影 --- 开始有分歧 上涨趋势 红K下影接上影 ---分歧但强势继续看新高 上涨趋势 红K上影接下影 ---承接力度大 但是只承接不追高 上涨趋势 黑K上影接下影 ---承接低可能出现短期顶 当然最好配合量能看，而且还要看上下影的长度判断力度。"

## BOLL 中轨判断市场强弱（2026-05-22 新增）

- **日分时回不到 BOLL 中轨以上**：市场偏弱

- **原文**（2026-05-22）：

## 量能与行情阶段的对应关系

```
量能持续放大 → 3-3 主升浪，满仓轮动
量能温和放大 → 行情健康，正常持仓
量能放大转缩量 → 短期见顶，减仓
量能放量跌破昨天红K 多一倍 → "昨天没涨"，立即减
量能持续缩量 → 3-4 调整，等待
量能缩至冰点 → 底部形成，等放量确认
量能再次放大突破 → 3-5 二次加速，重新加仓
快速放量 + 突破 → 真突破
慢速放量 + 不涨 → 假突破 / 放量智障
放量滞涨 + 高位 → 换手派发
B 反期间放转缩 → 过不了B高，C 杀进行中
日内 13:30 后突然放量主卖 → 量化主卖（控制仓位）
```
