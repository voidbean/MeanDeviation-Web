# Skill 07：风险管理与止损原则

## 概述

阿狼的风险管理以**提前预判 + 仓位控制 + 严格止损**为核心，不依赖运气，不做事后诸葛。核心理念：**能赚钱的时候多挣钱，需要自我保护的时候少亏点。**

2026-04 月起，阿狼遭遇了"创业纪录"——两个月中了 6 个暴雷票，对此完善了风险管理体系：
1. ST 风险股识别（看会计事务所是否出具报告）
2. 财报季操作规则升级（4 月 15 日后避雷）
3. 黑天鹅应对仓的固定 20% 配置

2026-05 月进入 3-5 末段后，阿狼又新增了两个新型风险剧本：
4. **沃什上台 / 新主席风险**（新主席上台后大概率回撤 10-15%）
5. **量化主卖再现**（5-21 下午 13:30 一把打穿 4140 → 4067）

2026-06 震荡筑底阶段，阿狼进一步深化了宏观风险判断：
6. **沃什的真实意图 = 改基数基准**（让通胀不再可怕，不是单纯加降息）——本轮牛市最大风险
7. **日元加息 = 延缓斩杀线**（最多加到 1，影响有限）
8. **上涨 vs 下跌的胜率不对称**（上涨买错最多不涨，下跌必须全对才能赢，不划算）
9. **弱势盘面保命主旋律 + 踩踏风险**（最大踩踏来自两融和机构出清）

## 风险等级分类

### 一级风险：日内波动（可忽略）
- **特征**：指数 1–2% 的日内波动，无放量，主线题材未破位
- **应对**：不操作，持仓等待
- **原文**（2026-01-22）：
  > "你们是怎么做到 1 个点不到的波动还能让心态崩的？"

### 二级风险：短期调整（减仓应对）
- **特征**：放量转缩量 + 收黑 K 破 5 日线，主线题材出现分歧
- **应对**：减仓至 50–60%，等待调整结束
- **止损位**：5 日线

### 三级风险：阶段性调整（大幅减仓）
- **特征**：指数跌破关键支撑（如 4000），主线题材集体退潮，融资盘开始出逃
- **应对**：减仓至 30% 以下，只留长线底仓
- **原文**（2026-03-23）：
  > "自从 4000 破了后，每天下午 1 点到 2 点半量化就硬止损，这里没钱不行，上不去的。"

### 四级风险：系统性风险（清仓观望）
- **特征**：流动性危机（黄金 + 美债同时大跌）、外围黑天鹅、指数持续放量下跌
- **应对**：清仓或极低仓位，等待情绪反转
- **原文**（2026-03-23）：
  > "现在就是流动性危机啊，还在问算不算。"

## 止损规则

### 个股止损
| 情况 | 止损动作 |
|------|---------|
| 收盘破 5 日线 | 减仓或清仓 |
| 跌破前一根红 K 最低价 | 卖出（趋势股） |
| 放量跌破昨天红 K + 量能多一倍 | 当昨天没涨，立即减 |
| 龙头风向标死亡 | 立即清仓板块内所有持仓 |
| 发布减持公告 | 立即清仓 |
| 严重偏离 BOLL 上轨后回落 | 减半仓 |
| 年报亏损 + 会计事务所未出具报告 | 立即拉黑，预防 ST |
| 板块发散到不正宗票 | 减核心，弃补涨 |
| 个股触发预设目标市值 | 拉升中逐渐减半 |

### 大盘止损
| 情况 | 止损动作 |
|------|---------|
| 指数放量跌破 5 日线 | 减仓至 50% |
| 指数跌破关键支撑位 | 减仓至 30% |
| 量化止损时段（13:00–14:30）| 不追，等量化结束（不要在这时间止损） |
| 量化主卖再现（13:30 缩转放）| 不能预判 → 控制仓位 = 唯一应对 |
| 两融余额大幅缩水 | 警惕，减仓 |
| 黄线下穿白线 + 大幅放量 | 停止加仓 + 高位逢高减仓 |
| 大盘日 K 跌破 60 线 + 结构未磨好 | 不抄底，等结构 |

## 黑天鹅应对原则

**核心思想**：黑天鹅不可预测，不要去预防，而是通过平时多挣钱来增加抗风险能力。

**原文**（2026-01-12）：
> "什么叫黑天鹅？黑天鹅事件指难以预测、突然发生且引发连锁反应并造成巨大负面影响的小概率事件，具有意外性、重大影响性和事后可解释性。这种不可预测的为什么要去担心他？……肯定是靠能赚钱的时候多挣钱，才能保证亏的时候有多点资本亏啊。"

**实际应对**：
- 主升阶段：哪怕黑天鹅来了，满仓也不怕，反而更激动（因为有利润垫）
- 调整阶段：仓位小，黑天鹅伤害有限
- 不确定阶段：30% 仓位，黑天鹅最多亏 10%
- **机构自救行情期间**：固定保留 20% 应对仓，用于黑天鹅低位抄底
- **3-5 末段**：20% 应对仓改为"**提现避让**"

**原文**（2026-04-14）：
> "剩下20%左右应对川普说话黑天鹅的抄底。"

**原文**（2026-05-20）：
> "出来的钱不会马上进去的。如果沃什上台能来个普跌 打出C底，那我才会考虑场外调回资金买 不然没差价 没意思。"

## 流动性危机识别

**信号**（需多个同时出现）：
1. 黄金大幅下跌（缺钱卖黄金换美元）
2. 美债大幅下跌（缺钱卖美债换美元）
3. A 股全面下跌（5000 多只股票同时跌）
4. 融资盘开始大规模出逃
5. 量化止损盘持续压制

**应对**：
- 不抄底，等情绪反转信号
- 只看谁在抄底，抄了多少钱
- 等技术底 + 情绪底共振

**原文**（2026-03-23）：
> "从技术上已经不能判断底了，现在是情绪反转才能出底。"

## ST / 暴雷股识别（2026-04-29 新增重点）

### 看 F10 的核心方法
1. 看年报或一季报是否亏损
2. 同时看会计事务所是否出具**内部控制审计报告**
3. 如果亏损 + 没有报告（或出"否定意见"/"保留意见"）→ **必拉黑**
4. 周末停牌、即将 ST 的票 = 此类高风险

### 阿狼的"创业纪录"
- 2026-03 ~ 04 中了 6 个暴雷票
- 太盛风能、天银机电等都吃了暴雷亏

- 上面要清理垃圾股，把退市流程跑通
- 不把垃圾股减少，就发不出优质新股
- 后续暴雷只会增多，不会减少

## 财报季风险（每年 4 月）

### 4 月 15 日鬼故事节点
- 4 月 15 日后：鬼故事越来越多（业绩不达预期）
- **应对**：尽量持有已发财报的票，未发财报的逐步减仓

### 业绩股埋伏机制
- 业绩股**埋伏机构** = 业绩前后必有动作
- **超预期** → 高开砸（已知信息提前买入）
- **不及预期** → 直接摁
- 阿狼明确说：不追业绩，去基本面+技术面+消息面共振的方向

### 业绩股选择规则（2026-04-19 完整版）
- 年报不好 + Q1 转好 = 健康
- 年报不错 + Q1 更炸裂 = 最强
- 年报亏损 + 一季度还亏损 + 无会计师报告 = ST 风险
- 重点：**已发业绩 + 低位 + 没暴雷可能 + 主线方向 = 板块内相对确定性票**

**原文**（2026-04-19）：
> "尽量排除掉自己手里还没出业绩的票，哪怕不想卖也尽量不要加 而那种平时不看业绩的 比如AI软这些，就找那种低位已经出了业绩保证他不会出雷的做，这些就是不确定性中的相对确定性。"

### 财报季操作排序
1. 已发财报 + 业绩好的：持仓
2. 已发财报 + 业绩一般但低位：可关注
3. 未发财报但主营业务稳定：观察
4. 未发财报 + 高位 + 有传闻：减仓
5. 未发财报 + 历史亏损 + 无审计报告：拉黑

## 量化交易时段风险

- **传统高风险时段**：下午 13:00–14:30（量化止损集中时段）
- **新规后新窗口**：13:30–14:00（更窄但更猛）
- **应对**：不在此时段追高，不在此时段止损（容易被两头割）
- **正确止损时机**：早上开盘或尾盘
- **量化新规 2026-04-06 实施**：高频认定阈值 ≥15 笔/秒（原 300 笔），撤单率 ≤ 15%，报单停留 ≥ 50 微秒 → 量化被弱化
- **影响**：量化打板能力下降 → 同板块走势不再高度同步 → 上下影线/盘口形态更"自然"
- **5-21 再现量化主卖**：说明新规后量化主卖依然存在，只是更难预判
- **原文**（2026-03-23）：
  > "每天的止损绝对不应该是下午 1 点到 2 点半这个时间，要么你早上卖，要么你尾盘卖。"

## 减持公告风险

## 上涨 vs 下跌的胜率不对称（2026-06-08 新增，核心风控逻辑）

阿狼在弱势行情反复强调的一条底层逻辑——**下跌行情的容错率远低于上涨行情**：

## 脆弱市场的踩踏风险（2026-06-08 新增）

弱势盘面下，市场结构脆弱 → 恐慌盘频发 → 可能形成踩踏：
```
市场脆弱 → 经常发生恐慌盘 → 恐慌盘可能形成踩踏
  → 最大的踩踏 = 两融出清 + 机构出清
  → 这些还没出现，大家已经受不了了（说明真正的大风险尚未兑现）
```
- **当前的"好事"**：A 股"确实先跌了"，微盘和老登股已经杀不出恐慌了（提前释放了一部分风险）
- **基金风格漂移**目前比例还不够（"比 21 年还差很远"），暂时不是系统性信号
- **应对**：弱势盘面保命，不赌反弹，等真正的恐慌盘 / 踩踏出清后才是机会
- **原文**（2026-06-08）：
  > "在弱势盘面保命是主旋律，因为市场很脆弱，脆弱就会经常发生恐慌盘，恐慌盘就有可能形成踩踏，而最大的踩踏是两融和机构出清，这些还没出现大家已经受不了了。"
