# Skill 04：板块轮动与题材选择逻辑

## 概述

阿狼的板块选择以**宏观主线 + 资金流向 + 龙头风向标**为核心，拒绝追热点、拒绝高切低到弱势板块。核心逻辑：**机构的钱只在机构趋势里轮动，风偏不同的板块之间资金不会直接跳转。**

2026-04 月起，阿狼新增了三个关键认知：
1. **机构行情 vs 柚子情绪行情**的根本区别
2. **板块内部子细分**的轮动顺序（半导体设备→材料、国算硬件、AI 软二线等）
3. **有梯队 vs 无梯队**板块的不同操作方式

2026-05 月进入 3-5 末段后，阿狼又给出了：
4. **半导体内部"设备 → 材料 → 电子化学品/玻璃基"**的完整产业链尾声节奏
5. **AI 大基建上下半年区分（上半年算力租赁，下半年 AIDC）**
6. **机构 → 柚子 → 散户的三段式收割剧本**
7. **科技板块虹吸下"非主线 = 更危险"**

2026-06 震荡筑底阶段，主线逻辑进一步收敛到"缩圈细分"，阿狼新增了几条关键认知：
8. **套定律（韬定律）= 华为芯片链 = 国产卡扩产**——海外卡买不到，国产扩产是唯一解，买华为强关联的国产放量环节材料和设备
9. **算力租赁逻辑被打断**（灰色拿卡渠道被禁，利通等暴跌）
10. **光切半导体材料**——光要剧烈洗盘时切回半导体材料细分（六氟化钨/钨等）
11. **新能源 + 有色 = 除通信+半导体外最大方向集合**（搅动血包，超跌反抽）

## 机构 → 柚子 → 散户：三段式收割剧本（2026-05-21 新增）

完整的板块退潮节奏：
```
阶段 1：机构抱团（"688 行情"）
  - 网格差价、每天涨一点
  - 共识强、心齐
  - 散户跟着主线买就能赚
阶段 2：柚子接力（"情绪行情 / 超短"）
  - 龙头票 / 中继票 出现连续抱团
  - 机构开始减仓，把筹码递给柚子
  - 散户进场易被逼空
阶段 3：散户接盘（"末段甩货"）
  - 柚子完成最后一波后离场
  - 散户被套在最高位
```

**触发阶段 1 → 阶段 2 切换的信号**：
- 板块轮动节奏开始"心不齐"，机构盘内出货明显
- 第一个具体表现：板块内出现"中继" / "新医生"这类纯柚子接力票
- 短期资金从核心转向边缘（如 5-21 半导体核心松动，量化主卖出现）

**原文**（2026-05-21）：

## 板块轮动判断规则

### 规则 1：高标退潮后，钱去哪里？
- **错误思维**：高位板块的钱会去低位没涨的板块
- **正确逻辑**：钱只去**下一个加速的同风偏板块**
- **案例**：AI 硬的钱 → 商业航天加速 → AI 软件应用（不会去白酒、地产）
- **2026-05-21 反例**：半导体松动后资金**没有**外溢到第二个能吃掉的方向 → 全市场被填坑 → 普跌
- **原文**（2026-01-12）：
  > "当时 AI 硬的钱是怎么出去的？你们老是觉得这些高的就要去那些低位没起来的，但是实际是商业航天加速起来才吃了 AI 硬的钱，那能接力商业航天的不就是下一个加速的 AI 软、AIDC、还有分散出来核聚变等等，这些钱会去白酒吗？地产吗？不会的，风偏就不一样。"
- **原文**（2026-05-21）：
  > "半导体这边还是正常走法 行情和预判的一样 甚至今天都是全天都有分段接盘的资金 问题在于 机构出来的钱没有外溢到别的板块 或者说大家都溢得很分散 没有能形成第二个吃掉半导体资金的方向。"

### 规则 2：高切低的时机
- **错误操作**：看见高位板块跳水就立刻切低位
- **正确时机**：高位板块加速结束 + 低位板块已经开始放量启动
- **关键认知**：早一步错过加速行情，晚一步跑不出来
- **原文**（2026-04-15）：
  > "什么时候做这个动作才是关键，早一步，你错过加速行情；晚一步，跑不出来不敢切低的。"

### 规则 3：弱势板块内选股
- 弱势板块找**强的和核心的**（不找补涨的弱势票）
- 高位板块的低位票 = 跌得少，不是机会
- 低位板块的弱势票 = 涨得少，不是补涨
- **原文**（2026-04-16）：
  > "弱势板块找强的和核心的。"
  > "存储板块整体高 和商航板块整体低 高位板块的低位票 也就是跌得少 而低位板块的弱势票 最多是涨得少而已。"

### 规则 4：机构 vs 游资主导的板块
- **机构主导**：稳定上涨，但弹性小，容易被压盘（如 CPO/光模块）
- **游资主导**：弹性大，但持续性短，需要每天当最后一天做
- **最优**：机构先进 + 游资接力（如商业航天初期）

### 规则 5：有梯队 vs 无梯队
- **有梯队**：龙头→次龙头→核心→补涨，可板块内轮动（商航、半导体、国算）
- **无梯队**：一波流，整板涨整板跌（机器人、纯情绪票如金螳螂）
- 有梯队板块适合调仓，无梯队板块只能一波操作

### 规则 6：风偏匹配 + 个股相性
- 找该方向与个人"相性对"的票（不是玄学，是数据共振）
- 相性不对的票拉黑
- **原文**（2026-04-08）：
  > "对的 一定要找该方向相性对的票 这不是玄学 是真正的道理。"
- **原文**（2026-04-29）：
  > "我早说了 选相性对的 所以有时候他们给我的票他们能挣钱 我去了就亏 那我拉黑不做就行 又不是没有票能买。"

### 规则 7：加速段虹吸下"非主线 = 更危险"（2026-05-15 新增）
- 加速期，**所有非核心科技资金会被虹吸**进半导体
- 低位非核心科技（5-20 案例：游戏、AI 软）反而更危险，因为资金被吸走
- 真正"安全"的板块：要么不在指数加速段里（如 5-14 白酒），要么本身就是科技核心

**原文**（2026-05-20）：

**原文**（2026-05-20）：
> "现在就是个循环三角 机构拉科技大票做最后冲刺 减出去科技小凳的仓位去潜伏别的中登方向 柚子开始做情绪抱团 散户开始大幅度割肉中登老登去科技小登。"

## 缩圈细分逻辑（2026-06 新增）

震荡筑底 + 赛道拥挤阶段，主线选择从"板块轮动"收敛为"**缩圈**"——资金过于集中，只有核心确定性方向能不断获得资金介入。

### 缩圈的层级（2026-06-09）
```
赛道拥挤 → 缩圈 → 资金过于集中
  ↓
大科技杀小科技 / 核心科技杀边缘科技 / 确定性成长杀故事画饼
  ↓
蹭概念的先塌 → 非核心"没新消息进核心圈"的死也死不了、机会也不大
  ↓
资金不断介入「确定性」，市场会给出来谁是核心确定性（看信息收集能力）
```
- **为什么核心细分不是平盘抗跌反而有所表现**：因为缩圈，资金过于集中
- **原文**（2026-06-09）：
  > "缩圈下只有核心科技有更确定的机会 一个是外围的业绩映射 一个是国内接下来的确定性路线 然后蹭概念的先塌 和非科技蹲一边……资金会不断的介入确定性 市场会给出来谁是核心确定性。"
- **原文**（2026-06-10）：
