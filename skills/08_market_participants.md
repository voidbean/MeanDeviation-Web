# Skill 08：市场参与者行为分析

## 概述

阿狼对市场各类参与者的行为有深入的理解，并将其作为判断行情方向的重要依据。核心思想：**读懂各类资金的行为逻辑，才能判断行情走向，而不是只看 K 线。**

2026-04 月起，阿狼新增了对**南向资金**、**机构自救行为**、**量化新规后行为变化**、**散户具体心理模型**的更详细描述。

## 一、GJD（国家队）

### 行为特征
- **工具**：沪深 300 ETF、上证 50 ETF、中证 1000 ETF
- **目的**：维稳市场，不是为了盈利
- **操作逻辑**：
  - 砸宽基 ETF = 警示市场，敲打过热资金（不是真的要砸崩）
  - 砸完立刻买回 = 开空对冲，不是真实卖出
  - 不砸科技个股 = 只打压指数，不针对有业绩的板块

### GJD 进场时机（2026-04 新认知）
- **不按点位，按时间**：本轮节点 = 4.16（一季报基本出完）
- **本质动机**：赶在双降之前进场（预期 5/6/7 月可能双降）
- **进场顺序**：
  1. 4.8 第一次（普涨形态，迷惑性大）
  2. 4.16 第二次（明显，下午用银行护盘到收盘）
  3. 4.17 第三次（确认）

### 信号解读
| GJD 动作 | 含义 | 应对 |
|---------|------|------|
| 砸沪深 300 ETF | 警示高标资金，敲打过热板块 | 高标减仓，业绩股不动 |
| 砸中证 1000 | 压制小盘股炒作 | 小票谨慎 |
| 买入 ETF（尾盘）| 护盘，维稳指数 | 可以持仓 |
| 用银行兜底关键位 | GJD 主动护盘信号 | 不卖，看普涨能否形成 |
| 不砸 = 行情安全 | 没有主动干预 | 正常操作 |

### GJD vs 机构自救的本质区别
- **GJD**：带来**普涨**，资金量级远超机构
- **机构自救**：**结构性高切低**，每天只有少数板块涨

## 二、机构（公募 / 私募 / 外资）

### 行为特征
- **特点**：体量大，建仓慢，持仓时间长
- **操作逻辑**：
  - 机构的钱只在机构趋势里轮动
  - 机构净流入 = 行情安全
  - 机构净流出 = 行情有风险
  - 机构会在特定位置压盘（防止过热被监管）

### 机构自救行为（2026-04 整月样本）
- **背景**：被金融板块砸盘 → 成本变高 → 必须自救
- **方法**：
  1. **不普涨**，只在高位减一点
  2. **轮动到低位**，把活动仓拿到下一个板块拉
  3. 散户被套在不同板块的相对高位
  4. 出现自救完后**有现金 = 短期机会**
  5. 等 GJD 或新增资金（双降）来时一起上
  6. 没有新增资金就压盘，吃日内差价
- **流程图**：板块 1 自救 → 出货 → 板块 2 自救 → 出货 → 板块 3...
- **散户接盘节奏**：散户买 ETF 被动加进去 + 看 F10 都不看就买低位个股 + 看见指数涨就追

**原文**（2026-04-14）：
> "其实很简单 现在机构做轮动 每一次个股轮高了 会有一批散户被套在当前相对高的位置 然后机构换低位的 当这种情况多了之后 散户会被套在不同的票的相对高位 而机构做完轮动套利出去有现金，如果有新进增量 比如GJD或者双降带来的大量资金 那就一起上，否则机构就顺势压一压 继续低吸吃这段的差价。"

**原文**（2026-04-15）：

### 信号解读
| 机构动作 | 含义 | 应对 |
|---------|------|------|
| 持续净流入 | 行情安全，可以持仓 | 持仓 |
| 开始净流出 | 行情风险上升 | 减仓 |
| 压盘（不让涨）| 防止过热，等待时机 | 耐心等待 |
| 解除压盘 | 时机成熟，开始拉升 | 加仓 |
| 高位放量滞涨 | 与新接盘交换筹码 | 警惕，看后续是否继续放量 |
| 机构集体性下杀某板块 | 集中"自救" 资金转移 | 跟随调仓，不要硬抗 |

## 三、游资（柚子）

### 行为特征
- **特点**：体量中等，操作灵活，喜欢高弹性小票
- **操作逻辑**：
  - 游资先进，机构跟进 = 最强行情（如商业航天初期）
  - 游资偃旗息鼓 = 板块行情结束
  - 游资自救 = 高位反抽，不可追
  - 游资喜欢：体量小、机构少、有热点、有活力的票

### 柚子情绪行情 vs 机构行情
- **柚子情绪行情**：一段不回调的龙头抱团，逼贪婪进场后收割
- **机构行情**：网格差价每天挣一点，没有强力情绪
- **判别**：龙头是否连续涨停且不回调 = 柚子主导

### 信号解读
| 游资动作 | 含义 | 应对 |
|---------|------|------|
| 大量净买入 | 板块启动，可以跟进 | 跟进 |
| 净买入消失 | 板块行情接近尾声 | 减仓 |
| 自救反抽 | 高位出货，不可追 | 不追 |
| 新进某板块 | 该板块短期有行情 | 关注 |
| 发散到不正宗票 | 板块即将走弱 | 减核心 |
| 螳螂这种"乱戳来"的票 | 纯柚子情绪，无基本面 | 不参与 |

## 四、量化交易

### 量化新规（2026-04-06 实施）后的行为变化

| 项目 | 新规要求 | 行为变化 |
|------|---------|---------|
| 高频认定 | ≥ 15 笔/秒（原 ≥ 300 笔）| 量化打板能力大幅下降 |
| 撤单率 | ≤ 15% | "秒挂秒撤"被禁 |
| 报单停留 | ≥ 50 微秒 | 必须留单 50 微秒以上 |
| 单日撤单 | ≤ 15% | 撤单总量受限 |

### 新规后的市场表现
- 同一板块走势不再高度一致（之前量化主导，板块同步性强）
- 涨停板家数下降（量化打板被限制）
- "无量大涨"减少
- 主观策略相对地位提升

### 量化止损时段（仍存在）
- **核心时段**：13:00–14:30
- **新规后影响**：止损动作弱化，但仍存在
- **应对**：不在该时段做减仓，等 14:30 后看方向

### 信号解读
| 量化动作 | 含义 | 应对 |
|---------|------|------|
| 13:00–14:30 大量卖出 | 量化止损，不是真实卖压 | 不追跌，等 14:30 后 |
| 跌破关键位后买盘 | 量化触发买入，被动托底 | 可以观察反弹 |
| 量化新规实施 | 规则改变，整体被动 | 关注政策变化 |
| 跟在大资金后面（4 月后）| 主动性下降 | 用主观策略主导 |

## 五、散户

### 行为特征 / 典型错误
- 追涨杀跌（高点追进，低点割肉）
- 不看 F10 就买入
- 看见指数涨就追，选择性遗忘利空
- 在量化止损时段止损（被两头割）
- 埋伏半个月，涨一天就卖掉
- **2024 后剧本玩家**：用炒股做引流/小红书涨粉（亏 8 万换几万粉，等同变相平台投流）

### 散户进场的具体节奏
- 早上不敢进 → 看指数涨起来 → 下午跟风进
- 进场时间集中在 14:00–14:30 拉升段
- 买"沙枪"——什么都买一点，低位的多买一点
- 进场对应"散户开始进来了 终于看见了"（顶部信号）

### 散户的"小作文/复牌"陷阱
- 复牌的券商直接跳水 + 大盘缩量 = 10 分钟内判断不可能破新高
- 复牌的财报小作文 = 已被定价过

### 散户的反复挨打模式
- 早上被杀出去 → 下午被吸引回去 → 第二天再被反复摁
- 8 成仓位 vs 5 成仓位的散户：8 成的睡不着，5 成的能补
- 卖出去后挂低位单防追高 = 实用反人性技巧

### 信号价值
- 散户大量进场 = 行情接近顶部
- 散户恐慌出逃 = 行情接近底部
- 散户开始晒收益 = 市场过热，注意分歧
- **散户做策略的方式（错误）= 没逻辑、靠猜** → 与机构思维相反

## 六、踏空资金

### 行为特征
- 行情启动时没有买入，等待回调
- 回调不来，最终在高位追进（成为接盘侠）
- 追进后行情见顶，被套

### 信号价值
- 踏空资金多 = 行情还有上涨空间（有人接盘）
- 踏空资金耗尽 = 行情接近顶部（没有新买盘）

**原文**（2026-01-12）：

**原文**（2026-01-12）：

## 七、南向资金（2026-04 新增重要角色）

### 行为特征
- 通过港股通通道流入港股
- 2026 年起逐渐成为重要风向标
- 阿狼自认胜率不如南向

### 关键数据（2026-04）
- 当月单日 +100E 以上 → 次日上证胜率 6/6（次日 +0.8% 以上）
- 5 次大额买入全部命中
- **2026-04-02 抄底 190E** + **2026-04-08 后续 188E** → 极强信号
- 2026-04-29 卖出 100E → 大概率次日冲高回落

### 应用
- 第二天大盘大致方向的辅助判断
- 不预测板块，但能预测指数方向

## 综合判断框架

```
行情方向判断：
1. GJD 是否在护盘？（看 ETF 资金流向 + 4.16 时间窗口确认 + 是否普涨）
2. 机构是否净流入？（看机构资金数据 + 是否结构性抱团高切低）
3. 游资是否活跃？（看龙虎榜净买入 + 龙头是否连续涨停）
4. 量化是否在止损？（看 13:00–14:30 时段 + 量化新规后的弱化）
5. 散户是否大量进场？（看两融余额、情绪指标、14 点后追高）
6. 踏空资金是否耗尽？（看量能是否持续）
7. 南向资金是否大额买入？（看港股通数据，> 100E 次日大概率涨）

→ 1+2+3 同时满足 + 普涨：强势行情，满仓
→ 仅 2 满足，1/3 不满足：机构自救行情，调仓不减仓
→ 4 触发：等待，不操作
→ 5 大量进场：警惕顶部
→ 6 耗尽：行情接近结束
→ 7 大量卖出：次日冲高回落预期
```

## 机构操盘特征观察小技巧（2026-04-10 新增）

- **"同花顺+8"形态**：典型的机构慢慢撬动型操盘，没有跳水也没有暴拉
- **指数缩量但板块涨**：机构在做轮动，不是普涨
- **大金融兜底关键位**：机构（甚至 GJD）的护盘技巧

**原文**（2026-04-10）：
> "你们知道指数为什么不跌吗 看看+8的同花顺 这就是典型的机构操盘方法了 我之前分享过多次 现在是我的舒适区。"
