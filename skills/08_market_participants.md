# Skill 08：市场参与者行为分析

## 概述

核心思想：读懂各类资金的行为逻辑才能判断行情走向，而不是只看 K 线。本 skill 把市场拆成 GJD、机构、柚子、量化、散户/老登、踏空资金、南向资金七类主体，给出每类的行为规律、可识别信号与对应操作。2026-07 起最大的框架变化在 GJD：从「按时间节点进场推普涨」变成**兜底政策底、只兜不拉**，市场底改由机构调仓后达成一致才产生；同期把 7 月下跌的责任主体明确为公募滚雪球踩踏 + 全球杀杠杆，不是上面砸盘。

## 一、GJD（国家队）

### 定位框架：政策底 ≠ 市场底（2026-07-23 起）

```
GJD 兜底  →  政策底（有了，但只兜不拉）
机构重新调仓 → 达成一致  →  市场底（要等）
```

- GJD 出手只保证不继续崩，不负责把指数拉起来；等「GJD 把行情做起来」是错误预期
- 兜底期指数被限制在区间里磨 → 对应打法是按 GJD 画的线做**指数级别的 T**，手上以 ETF 类为主（2026-07-23）

### 兜底 ≠「底部」

- 「3800 是底部」这种说法不准确：兜底只是一个**现象**，本质是 GJD 在慢慢低吸回补（2026-07-28）
- 动机假设（2026-07-27）：缓慢回补 3 月出清的份额，且是非常缓慢的过程
- 护盘的重点是「护」，不是拉起来给高位解套；但正因为他护，才能按指数技术级别去做 T（2026-07-28）

### 控盘程度有限

- 量级对比（2026-07-28）：之前卖了 2WE 以上，现在刚补不到 2000 个 E
- 推论：不存在「GJD 玩脱」，他的浮亏远小于场内杠杆盘；不是完全控盘阶段，所以**预测精度只能到区间，不可能精确到个位数**；兜底位置一定会被机构反复测

### 归因纪律：不要怪错人

- 2026-07 全月上面净流入各类宽基 **4500E 以上**，特别是沪深 300 → 大光跌得少、跌得慢是护盘结果
- **对照组**：没护盘的光纤和存储，跌幅与速度都远大于大光
- 结论：这段不是上面砸的，剩下的都是市场行为，是信心问题；评价原则是不要乱立靶子、实事求是（2026-07-31）
- 「稳指数 + 快速轮动收割散户」这个描述的主语是机构，不是 GJD（2026-08-03）

### GJD 进场识别（自 Skill 01 移入）

- **不按点位，按时间**：本轮时间节点＝ 4.16（一季报基本出完）；动机是赶在双降之前进场
- 2026-04 进场顺序：4.8 第一次（普涨形态、迷惑性大）→ 4.16 第二次（明显，下午用银行护盘到收盘）→ 4.17 第三次（确认）
- **辨识依据**：只有国家队才有普涨，机构只会结构性抱团

### 砸宽基 ETF 的用意（2026-01-21 案例）

- 砸宽基＝警示、敲打过热资金，不是要砸崩：宽基里都是按年起步的资金，散户不在里面，**杀伤性最小**
- 砸完买回来即可（是开空对冲）；副作用是把高标里的资金吓出去不少
- 不砸科技个股 → 只压指数，不针对有业绩的板块

### 阶段行为对照表

| 阶段 | GJD 行为 | 盘面含义 | 对应打法 |
|------|----------|----------|----------|
| 2026-04 进场期 | 按时间节点主动买、银行护尾盘 | 普涨可期 | 跟随，不减仓 |
| 2026-05 加速期（3-5） | 不再压制，机构主导 | 说杀就杀说拉就拉；机构获利后易心不齐 | 控仓位 |
| 2026-06 震荡筑底 | 盘中观察不到主动买盘 | 底不是 GJD 拖的，依赖场外资金 | 看场外增量 |
| 2026-07 起兜底期 | 持续出手，只兜不拉；画线明显 | 政策底成立，市场底待定 | 按线做指数级别 T，ETF 为主 |
| 2026-08 反弹期 | 位置被机构逐级试探 | 看不懂意图就会被收割 | 观察是否把兜底筹码做 T 减出去（2026-08-13 提出的观察点）|

## 二、机构（公募 / 私募 / 外资）

### 底层约束

- 机构的钱不是自己的：指数不在下跌通道时，主动型**不满仓会被投资人骂死** → 即使不想追科技，也必须把利润切去别的方向（2026-07-01）
- 调仓节奏受业绩驱动：过了业绩月后按业绩和指引调仓到下半年方向（2026-07-23）
- 机构的钱只在机构趋势里轮动；净流入＝安全，净流出＝有风险
- 机构在拉升的时候卖，不可能在跌停时卖（2026-06-25）
- **心不齐是共识达成的标志**：整套板块基本原理轮动完 → 纯机构抱团行情结束，后面拼本事（2026-05-21）；涨多了每个人都想提前卖、又没人做指数方向，市场就会偏离预期（2026-08-18）

### 剧本 A：测出兜单位置后的套利（2026-07-28，高概率剧本）

```
1. 测出某位置（当时是 3800）有 GJD 兜单
2. 缩量摁破这个位置 → 逼出一把恐慌盘
3. 同时跟随 GJD 兜单一起把指数拉起来
4. 兜起来后做个短差 → 把筹码交给回追进来的资金
```

- 本质是「套 GJD 的利」：信任最大控盘力量会在对应位置操作的资金，去套不信任者的利——属于市场行为，与 GJD 出招无关
- 落地形态（2026-08-11 案例）：机构逐级测 GJD 保的位置——今天看起来不是 3950，那明天试试是不是还在 3900

### 剧本 B：高标出货 ≠ 全部离场（2026-05-15 复盘）

```
机构高标慢慢减出
  ↓ 场内原低标非核心科技资金（割肉后）接盘
表面：非主线跌得更多   本质：场外资金进得还不够多
  ↓ 场内非核心资金心理防线到临界点
只要大跌普跌就调仓换股去核心科技（买跌不追涨）
  ↓ 场外资金被吸引进来
高标出货的机构 → 不断向下挂单，利用普砸阶段低吸
```

不要把「高标出货」误读成机构清仓，那是调仓；散户看到核心不跌、非核心惨跌，实际是资金集中度被强化。

### 剧本 C：公募滚雪球多杀多（2026-07-29 ~ 07-31）

- 触发条件：基金抱团过于拥挤，除海外映射外没有上涨动力
- 机制：公募「你一手我一手」互相卖出 → 别人卖所以我也卖 → 滚雪球
- 根因不是基本面，是**没有信心**，只能靠外力恢复（美联储降息可打断卖出）；同期真心做多的资金含海外资金仍在主动买，龙虎榜可验证
- 定性：全球性普跌杀杠杆 + 我们特有的公墓滚雪球多杀多，不是外资做空（要做空不会来融券又难、还 T+1 的市场）

### 其他行为规律

- **意图＝保中继**：中继能跌，但如果死了大家都出不去，所以它会被维护（2026-07-06）
- **静默等老登割肉**：出「超绝割肉盘口」前全体机构柚子静默，看量能就能识别（2026-06-04）
- **盘中也按 ABC 计划走**，看现象及时调整（2026-05-14 案例：下午本要诱多，没放量就收手按计划杀）
- **最终甩货对象不是散户**，而是后面不断追进来的机构被动持仓——公墓、ETF 指数基金、后知后觉的老登私募；散户只是被顺便收割（2026-05-15）
- **缩圈**：赛道拥挤 + 机构卡在抱团里等出场 → 资金过度集中到核心确定性，蹭概念的先塌（2026-06-09，详见 [[04_sector_rotation]]）

### 信号解读

| 机构动作 | 含义 | 应对 |
|---------|------|------|
| 持续净流入 | 行情安全 | 持仓 |
| 压盘不让涨 / 解除压盘 | 防过热 / 时机成熟 | 等待 / 加仓 |
| 高位放量滞涨 | 与新接盘交换筹码 | 警惕后续量能 |
| 集体性下杀某板块 | 集中自救、资金转移 | 跟随调仓，不硬抗 |
| 高标出货 + 向下挂单低吸 | 调仓而非离场 | 不要误判清仓 |
| 缩量摁破关键支撑 | 测兜单 + 逼恐慌盘 | 不跟着交出筹码 |
| 心不齐 + 踩踏出货 | 一致预期已破 | 控仓位，警惕量化卖盘 |

## 三、游资（柚子）

- 体量中等、操作灵活，偏好体量小、机构少、有热点有活力的票
- 游资先进机构跟进＝最强行情；游资偃旗息鼓＝板块行情结束；游资自救反抽＝高位出货不可追
- **柚子情绪行情** vs **机构行情**：前者是一段不回调的龙头抱团、逼贪婪进场后收割；后者是网格差价每天挣一点、没有强力情绪。判别看龙头是否连续涨停且不回调

### 收割链条

- 三段式（2026-05-21）：机构抱团 → 柚子情绪接力 → 散户接盘；第一个标志是板块内出现纯柚子接力票
- 四段式（2026-06-16）：核心圈内部不断出作文轮动上涨，最后先丢给量化，量化丢给柚子，柚子丢给散户
- 龙虎榜验证法（2026-05-26）：机构转给量化，量化再转回机构或柚子＝还能看；量化转给散户＝不能做了

### 信号解读

| 游资动作 | 含义 | 应对 |
|---------|------|------|
| 大量净买入 / 净买入消失 | 板块启动 / 行情尾声 | 跟进 / 减仓 |
| 自救反抽 | 高位出货 | 不追 |
| 发散到不正宗票 | 板块即将走弱 | 减核心 |
| 出现纯情绪接力票 | 机构出给柚子 | 提示卖点，谨慎参与 |
| 换名字重炒（物理 AI / 量子科技）| 纯情绪，看不懂 | 不参与 |

## 四、量化交易

### 新规（2026-04-06 实施）要点

| 项目 | 新规要求 |
|------|---------|
| 高频认定 | ≥ 15 笔/秒（原 ≥ 300 笔）|
| 撤单率 / 单日撤单 | ≤ 15% |
| 报单停留 | ≥ 50 微秒 |

新规后表现：同板块走势不再高度一致、涨停板家数下降、「无量大涨」减少、主观策略地位提升。2026-04 案例中定性为「量化被弱化，只能跟在大资金后面」；但 7 月起量化卖盘仍能造成全市场级别冲击（见冲突标记）。

### 网格阈值联动（2026-07-01，可复用机制）

- 光类 ETF 内部有大量 **±5% 网格量化**，上下到 3 个 15 分钟后都会有量化跟随策略
- 大哥单独调整较多时 → 看中继能不能守 **-7%**；守住了，光类 ETF 在 -5% 就有支撑
- 光方向普跌时 → 大哥反而跌得少、支撑来得更快，因为资金也不想引来量化踩踏
- 中继的地位相当于过去的茅台：日内波动只要在 -7% 内就没事（即容忍 ±14% 振幅）；一旦中继破位 → **触发全市场量化卖盘**，此时唯一动作是管住手（2026-07-06）
- 通用推论：资金大部分都按特定标号做网格（日内 ±5%、各种线、黄金分割），所以要观察个股资金盘口；票涨但不跟自己的线就不做

### 量化卖盘时段与识别

- 传统时段 13:00–14:30；新规后窄窗口 13:30–14:00
- 特征：早盘午盘缩量看不出迹象 → 13:30 后分时突然缩转放 → 一气呵成打穿关键均线
- 盘中无法预判，控制仓位是唯一办法；不在该时段减仓，等 14:30 后看方向
- 前兆：量化也去加速科技核心票＝全场吸血（2026-05-20 案例）
- 无行情时的消息面：某些「事情一直在做」的消息选在此时放出，与基本面无关，只是给量化找方向吃；这种消息硬吃属于没事找事，不参与
  > "看到了 垃圾行情里的垃圾消息 硬吃一波量化 属于没事找事做 治手痒的。" —— 2026-08-18

## 五、散户与老登

### 典型错误

- 追涨杀跌、不看 F10 就买、看见指数涨就选择性遗忘利空
- 在量化止损时段止损被两头割；埋伏半个月，涨一天就卖掉；做策略毫无根据靠猜（策略是应对，不是靠猜）
- **卖飞闭环**（2026-08-06）：卖出后一直想「是不是卖飞了」→ 最终在原位接回 → 结束一天操作
- **「高开就卖」的定式**一旦被种进去就只能追高：主观不想，但手管不住（2026-08-05）
- 大跌能扛，但外围不好时一拉回成本附近就会赶紧卖（2026-08-06）

### 卖盘的真正来源：连环爆（2026-07-31）

- 罪魁祸首是**广大杠杆散户和基金散户的连环爆**，不是 GJD 砸盘
- 机制上不可逆：基金赎回 T+3，卖出后无法反悔
- 结果（2026-08-02）：之前高点被套下来的科技仓位大部分都在 30% 以上
  > "之前高点被套下来的科技仓位大部分都在30%以上了" —— 2026-08-02

### 追高者＝带血筹码

- 反弹段追高的资金，下一次被杀就变成「带血的筹码」，被人套利（2026-07-31）
- 追高的拿不住，山脚的才能拿住：一震荡就被洗出去，哪怕后面还能涨也拿不住（2026-08-05）
- 前面挣不到钱的人是惊弓之鸟，容错极低——不用水下震荡，平开稍微震一下就能洗出去（2026-08-05）
- 唤回被套资金的目的不是让他们赚钱，而是要「响应速度」的时间差：唤回后再套一次，下次他们就不敢快速响应（2026-08-04）

### 最大的陷阱：右侧抄底共识（2026-08-18）

- 套人最多的不是 4000 附近（这里大家都会卖），而是**最后一次回落到 3900 附近**
- 那里会有人加满杠杆进场，因为已经坚信「3900 抄底就能挣钱」——典型的右侧理论思维
- 这个位置的大仓位才是机构本次要吃的利润，此前所有铺垫都指向这个目的

### 「大象关冰箱」三步逼老登

老登＝信仰红利、白酒、电力、银行、保险等防御板块的老投资者，占国内 50% 以上财产，不愿跟随新主线。

```
第一步：大家一起跌
第二步：科技先止跌（科技跌得少、反得多）
第三步：老登发现「抱团瓦解后钱会到我这边」的幻想破灭
  → 指数破位、抱团都没瓦解 → 这就是极限了 → 活跃资金认错去追科技
```

- 割肉盘口剧本（2026-06-04 ~ 06-05）：全体机构柚子静默等老登割肉 → 出现「超绝割肉盘口」→ 拉升让他们认错回去 → 浮亏浮盈置 0 轴附近，这些钱就活了
- 底部不需要老登追高，「他们只要买了 1 手就行」

### 撬动资金 与「散户是血包」

- **撬动资金**：从来没买过科技的散户下午买几手，就是撬动资金的含义；拉一个冷门防御板块亏不了多少，却能搅动 200-300E 活钱
- **散户＝血包**：机构尾盘开砸、收盘全天最低，就是一点不把散户当人
- **比较心理是死穴**：仓里一只 10 手的科技股很快覆盖 100 手老登股的亏损 → 心思泛滥 → 逐渐挪仓 → 最后一把爆掉
- **培养习惯路径**（2026-07-01）：不买科技 → 买科技 → 抱科技 → 抱科技指数 → 抱科技基金 → 完全对市场脱敏，最后进去的钱带不出来
- 买基金只看名字和排名、甚至不看持仓；科技指数强于个股时他们只能认输

### 信号价值

| 现象 | 含义 |
|------|------|
| 散户大量进场、14:00–14:30 追高 | 行情接近顶部 |
| 散户恐慌出逃 | 行情接近底部 |
| 散户晒收益 | 市场过热，注意分歧 |
| 空仓者说「刚好回调赶紧买点底仓」| 典型空仓心态，不代表真实买盘 |
| 认错去买 ETF 的资金增多 | 「非常好的肥料」，是同类票走势一致的原因 |

## 六、踏空资金

- 行情启动时没买、等回调；回调不来最终高位追进，追进后见顶被套
- 踏空资金多＝还有接盘力量；踏空资金耗尽＝接近顶部
- 场内大资金不急，场外踏空的很急——看两融就知道，高位带杠杆进来的钱很浮躁（2026-07-01 案例）
- 板块内开始有「杂毛」补涨＝踏空资金太多的表现（2026-06-23 案例）

## 七、南向资金（2026-04 ~ 05 历史样本）

- 通道：港股通；2026 年起成为指数方向的辅助风向标，阿狼自认胜率不如南向
- 2026-04 样本：单日 +100E 以上 → 次日上证胜率 6/6（次日 +0.8% 以上）；5 次大额买入全部命中
- 2026-04-02 抄底 190E、2026-04-08 后续 188E → 极强信号；2026-04-29 卖出 100E → 大概率次日冲高回落
- 2026-05-15 使用案例：南向净买 100E → 判断 B 反过程没结束，至少到下周一有机会
- 用法：只辅助判断次日大盘方向，不预测板块

## 综合判断框架

```
1. GJD 状态？只兜不拉 → 政策底成立、要等机构调仓；位置正被逐级测 → 支撑可能被缩量摁破一次；主动买 + 普涨 → 才是真进场
2. 机构在做什么？按业绩指引调仓 → 看新方向；高标出货 + 向下挂单 → 调仓不是离场；抱团拥挤互相卖 → 滚雪球风险；心不齐 → 一致预期已破
3. 柚子是否活跃？出现纯情绪接力票＝机构在往外递筹码
4. 量化阈值是否临近？中继 -7%、光类 ETF -5%、13:30-14:00 窗口
5. 散户/老登在哪一步？被诱进防御 → 割肉 → 认错追科技 → 加杠杆右侧抄底（最危险）
6. 踏空资金是否耗尽？看两融与量能   7. 南向是否大额买入？（历史样本：> 100E 次日大概率涨）

→ 1 普涨 + 2 净流入 + 3 活跃：强势行情       → 仅 2 成立：机构自救/调仓行情，调仓不减仓
→ 1 只兜不拉：区间做 T，ETF 为主，不预期反转  → 4 触发：管住手，不操作
→ 5 走到加杠杆右侧抄底：这是机构要吃的利润，反向警惕
```

## 机构操盘特征观察小技巧

- **「同花顺+8」形态**：典型的机构慢慢撬动型操盘，没有跳水也没有暴拉（2026-04-10）；**指数缩量但板块涨**＝在做轮动不是普涨
- **大金融兜底关键位**：机构甚至 GJD 的护盘技巧；**拉单一防御板块**是诱老登的核心手法（白酒 / 光伏 / 红利），不全面拉防御＝还不是最后顶
- **向下挂单**：高标出货后重新建仓的常用方法；**机构盘中 ABC**：盘中也按计划走，看现象随时调整
- **缩量偷偷拉**：远离前期关键位、大大的缩量拉上去，等散户发现要追回来时一放量就再套一波利，反复几次把成本拉开（2026-08-06）
- **信息不对称是前提**：机构分析个股基本面可能不行，但分析市场偷鸡情绪很强，且能从后台拿到看不到的数据（2026-05-15）

- **GJD 是否有固定兜底点位**：2026-08-06 说「哪怕是瞎的都能看出 GJD 在画图了，我提前多少天告诉你们他在 3800 兜底的」；2026-08-11 又认同「GJD 没有固定点位，只留子弹应对突发风险」并因此说「所以机构要测」。两者都是对 GJD 行为模式的判断，差异待人工判定。
- **收割链条是三段还是四段**：2026-05-21 表述为机构 → 柚子 → 散户；2026-06-16 表述为核心圈 → 量化 → 柚子 → 散户。量化在链条中的位置差异待人工判定。
- **量化的强弱定位**：2026-04-07 / 04-08 说量化被弱化、只能跟在大资金后面；2026-07-01 与 07-06 又给出量化网格阈值能引发全市场卖盘的机制。前者是新规刚实施时的观察，后者是阈值联动机制，两条可能同时成立。
